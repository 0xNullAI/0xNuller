# 0xNuller 交互式 HTML 产品演示

这是一个独立、零依赖的 16:9 优先交互演示。它复用 0xNuller 的真实设计令牌、Web 外壳结构、模块布局、设备名称与状态语言，但不会修改产品运行代码。

## 操作

- 点击画面、按 Enter、空格或右方向键：进入下一幕。
- 左方向键或 Backspace：返回上一幕。
- Home / End：跳到开头 / 结尾。
- 每次进入新页面时，该页动画会从头播放；页面不会自动翻页。

## 产品 UI 对照

- 主题、色彩、圆角、阴影来自 `@0xnullai/ui` 共享令牌。
- 外壳保持“左侧栏 + 内容区 + 唯一顶部设备栏”的真实结构。
- 设备使用产品实际名称：郊狼、负鼠、爪印、灵猫；输出状态使用 A/B 通道、上限、电量、待机和输出中。
- Agent、Voice、Video、Chat、Market 分别按现有模块的真实界面结构进行裁切和演示包装。
