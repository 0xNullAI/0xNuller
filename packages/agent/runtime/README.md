# @dg-agent/runtime

与界面无关的 Agent 会话运行时：上下文策略、流式事件、工具调度、权限、安全限制、传感器
触发与会话持久化。调用方注入模型、设备、权限和存储实现。

模型输入的说明与历史合用约 32,000 字预算，已注入的人设、私人 Memory、设备说明和本回合临时内容
会先占用预算，历史再按完整用户回合裁剪；服务器会话原文不受此限制。
单条超长的最新用户请求保持原文，避免截断停止或安全指令。工具调用/结果只保留当前回合完整链，
不从历史消息重放缺少结果的工具请求。私人会话可另外检索服务器授权的旧用户原话摘录与已确认记忆。

```ts
import { AgentRuntime } from '@dg-agent/runtime';
```

设备命令仍由 `@dg-kit/safety` 与权限服务执行，本包不会因登录状态自动授予控制权。

运行时内部边界：`runtime-tool-executor.ts` 只编排权限、租约、事件、追踪与设备分发；
`device-tool-availability.ts` 负责纯设备目标解析和模型工具可见性；
`runtime-policy-resolution.ts` 负责 Coyote/Opossum 共用的有界 clamp 收敛，并在不收敛时拒绝执行。
`runtime-action-evidence.ts` 在最终回复入库前核对明确的完成态表述与本回合工具结果；
没有对应成功结果时以运行时提示取代模型的“已执行”断言。计划保存、记忆候选和暂停的提醒草稿
不能当作外部任务、已确认记忆或已启用提醒。模型声称“已调用工具”须有实际成功的工具结果，
声称“已联网搜索”须有搜索工具返回的结果。此校验只覆盖明确识别的表述，工具执行记录与
最终执行边界仍是权威依据，不能把模型文字当作操作回执。明确提及郊狼或负鼠的完成态
表述还须有同类设备的成功回执，另一类设备的结果不能借用。
`runtime-tool-receipt.ts` 把本轮真实返回值绑定到 `runId`/`callId`，区分成功、拒绝、失败、
处理中和未确认；设备成功结果还须与本次工具对应的实际命令类型一致，指示灯结果还须匹配
请求的设备种类与颜色。普通 JSON、仅有 `ok` 的
设备返回、请求启动却返回停止的结果及待处理写入都不能充当本次成功收据。模型回复只可
依据成功收据叙述完成态。工具 owner 超时或执行后 trace 写入失败时，runtime 返回“状态未确认”，
停止本批剩余调用并要求核对实际结果，不能把可能已提交的动作报成确定失败或直接重试。
急停抢占队列时，已排队及执行中的旧设备命令带中断标记；其停止后的状态不能作为旧命令
完成的凭据，runtime 不发出执行成功事件并把该调用标为待核对。
未确认或仍在处理中的结果不再送模型自由总结；runtime 直接给出可核对的状态，并跳过本批后续
非停止工具。明确请求的停止工具仍可经过原安全执行链，避免前一项结果不明时阻断归零。
回合返回本地状态与收据，并在工具迭代预算用尽后仅允许一次无工具总结。本地状态只是诊断视图；
网页请求的服务器 `TaskRun` 已接入领取与客户端回报，但跨窗口恢复、收费和 UI 从收据展示状态仍须整链验收。
`RuntimeTaskRunLedger` 现在保留最近 50 条本实例运行状态，取消或执行中断时把未结算的工具调用
标为 `needs-review`。单轮内重复 `callId` 直接拒绝再次执行。调用方可注入 `taskRunReporter`：
网页用户请求须先取得服务器 `runId`，执行前等待 `beforeToolCall` 确认，结果以不含原始输出的
`client-reported` 收据回报；写入失败时不继续执行非停止工具，停止命令仍可达且回执转为未确认。
服务器只向首次创建运行的窗口签发内存执行令牌，领取不同 `callId` 也要验证令牌；账号切换或刷新
后不能恢复领取权，须读取已有记录并保守核对，不能自动重放未知副作用。
同一会话存在 active 运行时，服务器拒绝创建第二个运行；界面显示 active 或待核查记录，供刷新后核对。
没有服务器运行编号的内部/桥接回合不向模型提供工具。此本地记录不跨窗口持久，也不能作为服务器
验证设备动作的权威回执；服务器工具必须在自己的执行边界签发可信结果。
即使模型无视空工具清单而返回调用，运行时也拒绝该回合的非停止工具。工具提议 trace 写入失败时，
非停止操作在设备执行前拒绝；停止仍沿既有安全链尝试，且只能回报未确认状态。界面事件监听器的
异常会记录日志，但不会中断后续监听器或停止路径。
模型流式文字也先留在本回合内，不提前送进聊天预览或语音播放；只有最终回复经过工具结果核对后，
才发给界面。这样一次未执行的工具请求不会在最终纠正之前被用户看见或听成已经完成。

个人网页消息可携带 `characterId`（及可选 `relationshipId`）：首次绑定至会话 metadata，
已有角色不会被后续全局选择覆盖；桥接和群来源不能用这些字段建立私人关系绑定。
角色身份元数据不参与设备授权或工具权限。
`setSessionScene` 只允许私人会话在回合空闲时更新可选 `sceneId`（空字符串表示移除），
保留已绑定的 `promptPresetId` 与 `relationshipId`；群、桥接会话不能切换。

`contextualTools` 是可选的账号服务工具接缝：定义查询和执行均接收当前 `session` 与 `ActionContext`，
无需共享“当前会话”变量。状态变更先经过现有权限服务，随后沿用回合配额、取消、日志和结果展示。
默认设备 registry、策略与停止路径保持原样。
