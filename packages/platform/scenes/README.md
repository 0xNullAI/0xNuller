# @0xnullai/scenes

Agent 与 Voice 共用的个人角色／场景库，保存已从 Market 导入的卡片及历史自建内容、
当前选择、账户同步和 React 选择器组件。

```ts
import { loadScenes, updateScenes } from '@0xnullai/scenes';
```

个人内容同步实体数据。旧版内置隐藏偏好仍可读取，以兼容历史账户，但不再提供内置场景入口。
浏览器缓存按账号隔离；退出或切换账号时立刻隐藏上一个账号的卡片与编辑状态。旧版无账号归属的
本地卡片不会自动上传给下一位登录者，可在「我的角色与场景」明确选择导入到当前账号；
导入前先读取云端列表，云端暂不可用时保留原件且不上传。普通编辑只上传被修改的卡片，
避免把未修改的旧副本覆盖到其他设备刚保存的卡片上。

## 公开卡与个人内容

新角色和场景从 Market 导入；历史自建卡保持可读、可编辑。没有可用卡时当前选择为空，
旧版选中的内置 ID 自动回退到首张已保存卡或空值，不删除旧卡或聊天记录。

`SavedScene.characterCard` 是可选的原生 v1 公开元数据，包含简介、性格、开场、示例、标签、
作者与许可；保存、读取和账户同步保留它，非法元数据不影响原有场景正文。它不保存私人记忆、
关系昵称或群聊历史，也不代表完整 CCv2/CCv3 导入支持。详见
[角色卡调研](../../../docs/character-card-research.md)。

`./character-card` 提供不依赖浏览器的公开卡校验与模型上下文；`./character-editor` 提供
本地场景和 Market 共用的结构化字段编辑器。修改名称与人格字段独立于用户的私人关系。

Market 导入保存稳定的 `market-<itemId>` ID 与已采用的公开版本号，随账户场景同步。
从 Market 的「开始聊天」和个人列表的「从 Market 导入」入口都会先确认卡片快照及选择状态
已写入当前账户云端，再显示导入成功；前者随后打开会话。失败时保留已有的私人关系，
重试沿用相同的 `market-<itemId>` 身份。重复导入不会覆盖已经保存的个人改名或 Prompt。
个人列表导入时会重新读取当前可见的公开卡详情，避免使用过期列表快照或导入已下架卡；
角色可成为当前聊天对象，场景只进入个人场景库，不替换当前聊天角色。
作者改卡不会自动覆盖已导入角色；用户可在场景列表检查公开更新、预览后明确采用。
采用新版只替换此账号的人设快照，不换 ID，也不修改聊天、专属关系或记忆。
旧导入没有版本号时也可手动采用当前公开版本；下架或版本不可用时保留原快照。

公开内容的 `kind` 区分角色和场景：角色可成为个人聊天实体并使用该角色的专属关系与记忆；
场景只是可选择的环境与规则 Prompt，不创建专属关系、记忆或主动消息。旧版有有效
`characterCard` 的导入视为角色，纯 Prompt 导入视为场景。分类随本地快照和账户内容同步；
公开新版不能把同一已导入 ID 从角色改成场景或反向转换。

`./external-character-card` 接受标记完整的 CCv2/CCv3 JSON（上限 120 KB），将常规人物字段投影到
原生 Prompt/卡片，同时保留原始 JSON。原件中的 system prompt、角色书与资源引用不进入运行时，
更不授予工具或设备权限。Market 编辑器在此 JSON 投影之上解析 PNG/APNG 与 CHARX 的人物数据；
Market 将完整 PNG/APNG/CHARX 原容器保存在所属账户的私有 R2 文件中，在线草稿只同步受限
`sourceFileId` 与 `sourceFileName`；跨端恢复后仍可原样下载。公开角色不会包含私有文件 ID 或
附件字节，含未公开本地资产引用的原始 JSON 也不允许公开。编辑后重新生成完整容器及公开资产
分发尚未实现。

导入的公开头像保存为 `SavedScene.marketPortraitId`，仅接受 Market 场景 ID 与 UUID 资产 ID；
保存、同步上行/下行均保留，不包含私人 photo、任意 URL 或图片正文。重复导入不覆盖，只有
明确采用更新版本才替换（新版移除头像则清除引用）。旧导入缺少此字段时继续 emoji 回退。
视图可通过 `@0xnullai/market-client` 的 `fetchPublicMarketPortrait` 读取公开默认图；私人外观优先。

`@0xnullai/scenes/react` 的 `usePublicMarketPortrait(id)` 读取并解码公开图片，成功返回
页面内 object URL；无图/下架/坏图返回 null。切卡/卸载会 Abort 并 revoke；消费端不应持久化 URL。
Agent 按当前会话角色取默认图，Voice 按已准备的私人会话角色，Video 按当前选择的场景；
私有头像优先。已载入内存的公开图片不实时订阅下架事件，下一次读取由服务端可见性校验。
