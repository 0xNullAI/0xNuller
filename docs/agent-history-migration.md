# 旧 DG-Agent 聊天记录迁移

新版沿用旧 DG-Agent 的导出格式，可以直接导入，不需要转换工具。

1. 在旧版打开「设置 → 数据」，勾选会话并导出 ZIP。
2. 在 0xNuller 打开「设置 → 数据 → 导入」，选择该 ZIP。
3. 导入完成后，会话立即出现在 Agent 侧边栏；同 ID 会话以导入文件为准。

也支持旧版单个 JSON、旧版多会话 JSON，以及新版“一会话一 JSON”的 ZIP。解析失败只会拒绝
当前文件，不会清空已有记录。

已登录时，导入结果先写入当前设备，再通过 Agent 会话同步上传到账户；离线导入仍然可用，
恢复网络后继续同步。模型 API Key、设备连接和设备权限不属于聊天记录，不会被导入或上传。
