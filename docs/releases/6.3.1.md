# 0xNuller 6.3.1

本版本统一了 Agent、Voice、Video 与 Chat 的 AI 多设备选择，并补齐场景、上下文和发布安全边界。

## AI 与多设备

- Agent 与 Voice 可同时理解并控制多台郊狼；同类型、同名称设备仍以独立临时目标呈现。
- Chat、Video 和通用设备同样按物理实例精确选择，不按名称猜测、合并或广播命令。
- 每次输出前重新检查目标身份、连接、权限、模块租约和安全上限；断开重连后的旧目标立即失效。
- 挂断、切换模块和全局紧急停止会中断各目标的排队命令，防止停止后恢复输出。

## Video 与场景

- Video 与 Agent、Voice 共用场景库和当前场景选择，可直接选择内置或 Market 场景。
- 未选择有效场景时显示明确的待选择状态，并使用精简的内部视觉运行规则，不再静默套用背景。
- Video 从统一的已连接设备列表中让 AI 自主选择精确输出目标，无单独设备选择逻辑或实验开关。

## 上下文与文档

- AI 上下文只包含当前连接且可输出的设备；断开、故障、仅遥测或仅保存过设置的设备不会进入提示。
- 减少没有工具结果支撑的历史内容，降低模型误报“已经执行设备操作”的概率，且不显著增加 token。
- 精简 `AGENTS.md`，重写 Video、Chat、Voice、通用设备和部署说明，使使用与维护边界更容易查阅。

## Market 与发布

- 用户场景不再写入产品迁移或内置场景；“雾境异兽同行者”作为 Market 内容独立发布。
- GitHub 发布流程在部署前执行只读数据库版本门禁，避免代码与线上结构不一致。
- Web 与 Android 使用统一版本 `6.3.1`，Android 内部版本号为 `6003001`。
- Android APK：`0xnuller-v6.3.1.apk`。
