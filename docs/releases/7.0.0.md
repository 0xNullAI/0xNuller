# 猫愿 7.0.0

0xNuller 更名为「猫愿」。本版本把 AI 统一到猫愿自己的服务上，重做设置，并加强多设备安全。

## 猫愿模型

- 聊天、摄像头观察、记忆、长对话摘要和主动消息统一使用猫愿模型，不需要自己的 API 密钥。
- 实时语音、语音消息转文字和朗读改用新的语音服务，通话中仍可控制设备。
- 记忆和长对话摘要对所有用户免费。
- 使用自己的 API 时只支持文字聊天，在「我的 → AI → 高级 → 自定义模型」中填写 OpenAI 兼容接口。
- 角色视频下线；图片生成暂未开放。

## 设备与安全

- 每台郊狼和负鼠都可以单独设置 A、B 通道上限，与所有设备共用的上限一起生效，取较低值。
- 设备列表显示连接状态、电量和当前生效的上限。
- 急停仍会同时停止所有已连接设备。

## 聊天

- 真人私聊和群聊支持搜索聊天记录。
- 所有群统一完整保存历史，连续 30 天无人进入后回收；私聊不受影响。
- 修复首次打开聊天时可能被带到账户页、群聊连不上的问题。

## 设置

- 「我的」重新分组：通用、设备与安全在最上方，角色与场景、AI 在「陪伴」中。
- 个人记忆移到 AI 中，按类型分组，可搜索，每条记忆单独编辑。
- 通知并入通用；波形库并入设备与安全；数据并入关于。
- 设置页统一使用列表、开关、分段选择和滑块。

## 移除

- Windows、macOS 桌面版不再发布，请使用网页版或 Android 版。
- 移除实验性的通用设备（非 DG-Lab）支持、内置帮助文档和系统推送；新消息以应用内未读提醒。

## 其他

- 新增《用户协议》和《隐私政策》，可在「关于」中查看；注册时需确认已年满 18 岁并同意。
- 应用出错时会匿名上报错误类型（不含聊天内容和账户信息），帮助我们更快修复问题。

- Android 安装包更名为 `maoyuan-v7.0.0.apk`，旧版本仍能收到更新提示。
- 设备强度、停止和紧急停止的安全链没有放宽。
