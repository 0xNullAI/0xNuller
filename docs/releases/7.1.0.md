# 猫愿 7.1.0

安卓版开始支持热更新：以后界面上的改进会在后台自动下载，下次打开 App 就是新版本，不用再重新安装。

## 安卓热更新

- 这一版需要最后手动安装一次安装包；之后的界面更新都会自动送达。
- 新版本下载完成后，顶部会提示「新版本已就绪」：可以等下次打开自动更新，也可以点「立即重启」。连接着设备时不显示「立即重启」，不会打断正在进行的输出。
- 更新包都经过签名，逐个文件校验，只有猫愿官方发布的版本才会被安装；聊天记录、角色和设置都保留在原处。
- 如果某个版本在你的手机上打不开，App 会在几次启动后自动退回上一个能用的版本。
- 「设置 → 关于」显示安装包版本；需要时可以「恢复安装包自带的版本」。
- 涉及蓝牙等系统能力的更新仍然通过安装包发布，到时会照常提示下载。
