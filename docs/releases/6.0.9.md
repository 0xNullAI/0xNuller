# 0xNuller 6.0.9

这是一次发布基础设施整理版本，产品功能与 6.0.8 保持兼容。

## 发布流程

- `dev` 只负责代码集成和生成 Kit Version PR，不再发布 npm 包。
- 经过验证的 `main` 是 npm、Cloudflare 和签名产品产物的唯一生产发布源。
- Product Release 与 Kit Release 已拆成独立工作流；Kit 不创建或修改 0xNuller 产品 Release。
- 产品发布采用 `dev → main` squash 快照，符合 main 的线性历史保护规则。
- 产品发布前会拒绝尚未消费的 changeset，避免 main 重复创建包版本 PR。

## 产物

- 统一产品标签：`v6.0.9`
- Android 安装包：`0xnuller-v6.0.9.apk`
