# 0xNuller 6.0.13

这是一次 Cloudflare 服务整合发布，网页端与 Android 端使用同一版本。

## 迁移

- 将历史 Agent、Chat、Voice、Market 与 Wiki 子域永久迁移到统一主站，并保留查询参数。
- 新增受限的跨域浏览器数据迁移，安全合并旧站保存的设置、房间信息、会话与自定义波形。
- 旧 API 与 WebSocket 端点明确返回退役状态，不再依赖历史 Worker。
- 新增主站 `/wiki` 入口，旧 Wiki 域名直接进入统一文档界面。

## Cloudflare 整理

- 移除历史 `dg-chat`、`dg-voice` 与 `dg-market` Worker，以及旧 Chat/Voice Durable Objects。
- 移除历史 `dg-agent`、`dg-wiki` 与 `dg-web` Pages 项目。
- 保留当前产品仍在使用的 `dg-market` D1、`dg-chat-media` R2、账户数据库和用户照片。
- 发布与回滚流程现在覆盖浏览器迁移和旧域兼容 Worker。

## 安全与隐私

- 迁移端点严格校验来源、窗口、nonce 与字段白名单。
- 不迁移登录 Token 或 sessionStorage，也不删除旧浏览器中的原始数据。
- 本次发布不改变设备强度、命令、租约、权限或紧急停止逻辑。

## 验证

- Repository、Product、DG-Kit 与 DG-MCP CI 全部通过。
- 五个旧域永久重定向和五个迁移端点均已验证。
- Web、Auth、Chat、Market 与 Voice 生产烟测通过。

## 交付

- Web：与本版本同步部署。
- Android：`0xnuller-v6.0.13.apk`。
- 统一产品标签：`v6.0.13`。
