# 0xNuller 6.3.6

本版本补全 Market 内容管理，并修复发布前全仓检查发现的问题。

## Market

- 登录账户可以删除自己上传的场景。
- 单人场景可以修改完整剧本提示词；多人场景可以修改世界观、推荐人数、AI 参与方式和角色。
- 编辑与删除权限继续由服务端按上传账户校验，其他账户只会看到“无权限”。
- 编辑保存后，详情预览、复制 JSON 和下载文件会立即使用新内容。

## 维护

- 修复宣传页脚本缺少浏览器全局声明导致的全仓 lint 失败。

## 版本

- Web 与 Android 使用统一版本 `6.3.6`，Android 内部版本号为 `6003006`。
- Android APK：`0xnuller-v6.3.6.apk`。
