# 0xNuller 6.0.2

This release completes the account-backed unified platform rollout and carries the signed Android
application forward from DG-Agent without changing its package identity.

## Highlights

- Restores the complete Agent model controls, streaming replies, local history import, and account
  session synchronization.
- Unifies Bluetooth entry points, shared safety limits, themes, dialogs, sheets, logos, and responsive
  Android safe-area behavior across Control, Agent, Voice, Chat, Market, and Playground.
- Adds account-backed rooms, direct messages, profile photos, scenes, waveforms, Agent sessions, email
  verification, password recovery, and AI usage accounting.
- Hardens room ownership, media authorization, Market ownership, R2 cleanup, D1 migrations, registration
  uniqueness, and concurrent device safety behavior.
- Adds automatic Cloudflare deployment, rollback tooling, package release verification, and automatic
  signed Android releases for new versions merged to `main`.

The Android package remains `ai.nullai.dgagent`, so existing DG-Agent installations signed with the
original release certificate can upgrade in place.
