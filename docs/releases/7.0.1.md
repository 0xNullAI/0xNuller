# 猫愿 7.0.1

安全修复，以及给新用户的引导和官方角色。

## 设备安全

- 修复：私聊或群聊里有人按住「开火」时，设备主人按「归零」或紧急停止后，输出会在 0.3 秒内被重新拉起。现在停止会结束所有正在按住的开火，对方必须松手再按才会重新加强。
- 修复：远程切换负鼠的节奏一直提示「参数缺失」。

## 新用户引导

- 第一次进入时，消息页会显示「欢迎来到猫愿」，可以直接去挑角色、创建角色、连接设备或找朋友。
- 创建角色时，「基础 Prompt」改叫「人物设定」，并提供「按模板填写」，照着填就能写出一个完整的角色。

## 发现

- 新增 15 个官方角色和 3 个官方场景，由「猫愿官方」发布。改编自 Foreverse 团队的 character-card-skills（CC BY 4.0），原作者和许可写在详情里。

- 角色详情页重新排版：大封面、开场预览、单栏阅读，长内容可展开，对话示例以聊天气泡显示。

## 其他

- 修复：弹窗打开时会先出现在左上方，再跳回中间。
- 修复：快速连点「发布角色」会发布两张一样的角色。
