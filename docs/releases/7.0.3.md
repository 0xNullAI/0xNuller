# 猫愿 7.0.3

角色和场景都可以私有或公开，本地角色卡文件可以直接导入；猫愿模型可以把大型剧本整理成角色卡。

## 私有与公开

- 「我的 → 角色与场景」新增「新建」：可以新建只有自己能看到的角色或场景。
- 新增「导入文件」：导入本地的角色卡文件（CCv2／CCv3，JSON、PNG、CHARX），保存为私有角色。
- 每张卡标出「私有」或「来自发现」，并且都有「聊天」按钮：角色开始和角色聊天，场景开始由 AI 主持的场景聊天。
- 「发现 → 创建」可以选择「公开发布」或「仅自己可见」；仅自己可见的卡只保存到你的账号，不出现在发现里。

## 聊天

- 新建聊天的菜单里也列出你的场景，私有和公开的场景都能直接开始场景聊天。

## 整理剧本

- 很长的剧本可以用猫愿模型整理：在「我的 → 角色与场景」里点「拆分角色」，或在「发现」的剧本详情里点「提取角色」。
- 先显示预计消耗的 Credit，确认后才开始；模型列出剧本里的人物，你选择要哪些，再逐个整理成可以单独聊天的角色卡，也可以同时保存剧本的场景。
- 整理出的卡都保存为私有卡，只有自己可见。来自别人公开剧本的会标注「改编自《原剧本》」和原作者，只供自己聊天，不能再公开发布。
- 按实际用量扣 Credit，可以随时停止。
