# 0xNuller 6.0.6

- 修复 Android 旧版 WebView 无法识别 CSS Cascade Layers、进入应用后界面无样式和布局错乱的问题。
- 修复状态栏、刘海与三键导航安全区在非全面屏 Android 设备上遮挡内容的问题。
- 修复 Android 启动页持续闪烁、无法进入主界面的问题。
- 修复旧版 Android WebView 缺少 `Object.hasOwn` 导致 Agent 模块加载失败的问题。
- 修复软键盘弹出后遮挡底部输入框的问题。
- 修复 Android 11 及以下蓝牙插件漏传定位权限请求、权限检查误报成功但始终扫描不到设备的问题；同时分别提示蓝牙关闭、定位服务、附近设备权限与永久拒绝，并区分“正在扫描”和“扫描完成未发现”。
- 重构 Control 为可横向滑动切换的主机控制台：郊狼和负鼠统一使用双通道强度、波形选择与一键开火，负鼠不再显示灯光颜色；灵猫和爪印只在顶部设备栏显示读数。
- 在 Android 统一外壳的房间页和移动端侧边栏恢复明确可见的“退出/关闭私聊”入口。
- 替换 Tauri 默认安卓桌面图标为 0xNuller 品牌图标。
- 统一源码与产品版本为单一 `vX.Y.Z` Release，并在同一 Release 附带签名 APK。
- 安装包统一使用清晰的 `0xnuller-vX.Y.Z.apk` 文件名。
- 在网页版说明入口下方新增 Android 版下载按钮。
