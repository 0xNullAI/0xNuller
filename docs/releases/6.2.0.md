# 0xNuller 6.2.0

本版本新增独立 Video 工作区，并加入 Web 与 Android 内嵌的实验性通用振动设备支持。Control、Agent、Voice 与 Video 共用同一设备运行时和安全边界。

## Video

- 新增独立 Video 模块，与 Agent、Voice 分别使用各自的 AI Provider、凭据、模型、Prompt 和会话。
- 支持原始画面与模型输入双预览，以及镜像、旋转、亮度、对比度、阴影、高光、锐化、裁剪和输出尺寸调整。
- 使用最新帧异步观察，摄像头刷新、模型判断和设备效果互不阻塞，不建立图片队列。
- 图片仅作为当前推理的临时输入，不进入会话历史、浏览器存储、账户同步、导出或 trace。
- 每次运行必须明确授权物理目标、功能、强度上限、增强选项、持续时间和观察节奏。

## 实验性通用设备

- Web 内嵌 Buttplug Web Bluetooth/WASM，无需 Intiface Central 或外部服务器。
- Android 使用内嵌 Rust/BLE backend，保持应用内完成扫描、连接与控制。
- 首批能力包括 Vibrate、Battery 和 RSSI；不开放 Raw、任意 BLE 写入或协议字节。
- 实验功能默认关闭，开关仅保存在当前浏览器或 App，不同步、不导出、不迁移。
- Control 提供按设备与功能区分的人工控制；Agent、Voice 与 Video 仅能使用运行时签发的精确 `deviceId + featureId`。
- Android 的传统 DG 设备扫描与通用设备扫描使用互斥所有权，避免两个 BLE scanner 并发竞争。

## 安全

- 四个模块共用一个 DeviceRuntime、工具目录、executor、设备租约和 safety generation。
- 每次原生写入前重新检查会话、拓扑、安全代数和 lease epoch，拒绝断线重连或 lease ABA 后的迟到命令。
- 振动按设备原生步数向下量化，并受冷启动、增量、强度上限和短时 output lease 限制。
- 页面隐藏、Android 暂停、模块切换、授权到期、设备丢失或 watchdog 都会触发停止。
- 普通停止精确作用于授权功能；目标身份失效时升级为全局停止。
- 停止失败会锁存故障并显示警告，不会把传输回执声明为已确认的物理状态。

## Market

- 加强场景导入结构、Prompt 长度和重复 Market ID 校验。
- 管理员内容页支持波形与场景分类，并在服务端分页前筛选。
