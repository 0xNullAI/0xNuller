# 猫愿 7.1.3

这一版专门处理卡顿和一批隐藏问题。只更新界面和服务器，安卓会通过热更新自动送达，不需要重新安装。

## 更流畅

- 长聊天不再拖慢整个应用：先显示最新的 50 条，往上滑再逐批显示更早的消息。别人连着设备时，聊天也不会跟着反复刷新。
- 连接郊狼后，设备没有变化时不再让整个页面每秒重绘十次。
- 切到别的页面后，后台的聊天不再占用性能；角色库不再反复读取。
- 头像、角色立绘只加载一次；首屏需要加载的内容更少，消息列表更快出现。
- 翻看旧消息时，新消息不会把你拉回底部，会显示「有新消息」。

## 更可靠

- 打开任何弹窗时，左上角都会出现「停止设备」，不用先关掉弹窗。
- 正在回复时按「停止」一定会生效，即使回复还没真正开始。
- 一个对话正在回复时，其他对话不再被锁住；不会再出现别的对话的消息。
- 修改设置或角色不再意外中断正在进行的回复。
- 群聊解散或被移出后会显示原因，不再无限重连；网络切换后可以立即重连。
- 应用有新版本时，先停止设备再刷新，不会突然中断。

## 安全

- 群成员发出的异常消息不会再让其他人的聊天崩溃。
- 别人无法再借撤回删除你发的图片或语音。
- 远程控制的参数会先检查再执行；别人分享的波形需要你允许此聊天控制设备，且不会覆盖你已有的波形。
- 被封禁的账号会立即失去访问。
