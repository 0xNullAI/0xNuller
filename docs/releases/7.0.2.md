# 猫愿 7.0.2

场景可以单独聊天，猫愿模型能看你发的图，生成图片开放，发现页按综合热度排序。

## 场景聊天

- 场景和角色分开：在「发现 → 场景」里点「开始聊天」，不用选角色，AI 会主持这个场景，描述环境、推进事件、扮演场景里的人物。
- 场景聊天以场景命名，显示场景封面；再次点「开始聊天」会回到上次的对话。
- 和角色聊天时，仍可以在聊天设置里给角色加一个场景作为环境。

## 图片

- 生成图片开放：在聊天里点「＋ → 生成图片」，可选「让角色出镜」。
- 聊天里发的图片，点「让 AI 看图」后猫愿模型可以看图回答，不需要自己的 API。

## 发现

- 默认按「综合排序」：结合浏览、下载、收藏和发布时间，最新发布的不一定排在最前，受欢迎的内容会保留更久。「最新发布」等排序仍可在筛选里切换。

## 其他

- 生成图片面板改用应用统一的配色。
