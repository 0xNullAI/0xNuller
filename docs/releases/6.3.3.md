# 0xNuller 6.3.3

本版本优化移动端空间利用，并完成开发流程收拢。

## 界面

- 移动端菜单、模块名和设备连接状态合并为单行顶部栏，减少首屏占用。
- 压缩设备状态栏，将 Agent 诊断入口移入设置，并上移欢迎输入区。
- Chat 公开房间列表支持显示与隐藏，长列表限制高度并独立滚动。

## 维护

- 将四条分域 CI 合并为一条按改动范围运行的统一 CI，版本准备仅在 Changeset 变化时启动。
- 收拢测试责任域、维护文档和历史快照，保留现行说明及关键回归覆盖。

## 版本

- Web 与 Android 使用统一版本 `6.3.3`，Android 内部版本号为 `6003003`。
- Android APK：`0xnuller-v6.3.3.apk`。
