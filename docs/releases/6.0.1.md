# 0xNuller 6.0.1

本次更新集中修复 Android 与 Agent 的实际使用体验，并补齐账户、聊天和发布链路。

- 修复 Android 状态栏、底部安全区、软键盘遮挡和下拉菜单无法操作。
- 修复 Agent 设备连接、用户消息即时显示与流式回复。
- 恢复上下文策略、回复多样性、模型搜索、模型刷新与连接测试。
- 恢复模型能力信息、API Key 记忆开关、自定义端点和严格模式。
- Chat 侧栏只显示已加入房间，无房间时展示公开目录。
- 完善房间搜索、账户头像、个人简介和跨平台同步。
- 增加注册限流、Cloudflare 回滚和 npm 发布包校验。

Android 安装包继续使用原应用标识 `ai.nullai.dgagent`，可直接覆盖升级。
