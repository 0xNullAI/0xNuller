# 猫愿 7.2.0

这一版更新了安卓原生层，需要安装新的安装包；网页版刷新即可。

## Credit 改为卡密兑换

- 购买 Credit 改为兑换卡密：在「我的 → 账户 → Credit」粘贴 64 位卡密即可到账。
- 档位：¥6 → 1,000、¥30 → 5,000、¥68 → 12,000、¥128 → 23,000、¥328 → 60,000、¥648 → 120,000 Credit。
- 每张卡密只能使用一次；连续输错多次会暂停兑换一段时间。
- 不再接受新的充值订单。已有订单仍可查看、取消或申请退款。
- 管理页按概览、账单、卡密、对账审核、赠送、内容与运行分页整理，账单可按用户、类型和日期筛选并按天汇总。

## 设备安全

- 用户设置的强度上限会写入郊狼本身，设备自己也会拒绝更高的强度。
- 安卓应用切到后台或退出时，由原生层直接停止所有设备，不再依赖页面。
- 设备超过 1.5 秒没有收到任何指令时，自动发送一次停止。
- 急停指令没能送达设备时会如实提示，不再显示为已停止。
- 网页版可在「设备与安全 → 切到后台时」选择保持当前输出 5、10 或 30 分钟；期间只能停止或降低，到时自动停止。
- AI 会知道期间发生了什么：切到后台、急停、切换模块之后，它不会以为设备还在运行，继续前会先确认，并从低强度重新开始。

## 安卓

- 登录凭据和自带的 API Key 改存在系统加密存储里，并关闭了应用数据备份。
- 语音通话期间屏幕保持常亮。
- 摄像头或麦克风被拒绝时会立即提示，并提供「去设置」按钮。
- 自定义代理和模型地址只接受 https，界面会提示。
- 蓝牙写入更可靠：停止指令优先发送，断开后不会卡住后续指令。
- 热更新包写入后会校验，损坏时自动退回上一版本。
