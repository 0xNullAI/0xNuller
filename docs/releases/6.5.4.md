# 0xNuller 6.5.4

本补丁修复 Credit 模型不可用的问题，并整理模型与管理设置界面。

- Credit 模型改为通过 Cloudflare Workers AI 直接运行，不再依赖第三方接口或 API Key。
- 增加基础、均衡、强力三个模型档位，并在选择器中标记常规请求的预计 Credit。
- 三个档位均支持 Agent 工具调用；托管入口仅处理文字，视觉模型继续使用独立设置。
- 修复网页 Cookie 登录可能被占位 Authorization 覆盖的问题。
- 自有 API 服务商选择器改为分组、自适应的搜索菜单，改善桌面和 Android 体验。
- 管理面板中的 Credit 赠送入口移动到人工充值之后。

产品版本：`6.5.4`；Android 内部版本号：`6005004`。
