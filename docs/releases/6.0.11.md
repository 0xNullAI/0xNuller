# 0xNuller 6.0.11

这是一次蓝牙连接、设备识别与 Agent 多设备稳定性补丁发布，网页端与 Android 端使用同一版本。

## 修复

- 修复 Chromium 在 GATT 连接刚完成时偶发断开、随后无法读取服务的问题；遇到 `GATT Server is disconnected` 时会先重新连接，再重试协议握手。
- Agent 现在可同时连接多台郊狼，每台设备使用独立协议实例、命令状态和紧急停止路径，不再在连接第二台时提示“设备已连接”。
- Agent 顶部设备栏按稳定设备 ID 展示和断开每台郊狼；全局紧急停止会覆盖全部已连接主机。
- 郊狼电量改为读取标准 BLE Battery Service；无法读取时保持“未知”，不再错误显示为 0%。
- Android 在权限检查后预热 DG-Lab 设备发现，并复用仍然有效的命名扫描结果，缩短打开设备选择器后的等待时间。

## 验证

- 全仓 158 个测试文件、1234 个测试通过。
- Lint、类型检查、结构检查和 Web/Android 前端构建通过。
