# 0xNuller 6.0.14

本次补丁版本集中修复 Agent 的场景、权限和多设备体验，Web 与 Android 使用同一版本。

## Agent

- 场景选择列表新增「从市场导入」，导入后立即选中，重复导入不会产生副本。
- 移除内置「地狱岛冒险」场景；旧的无效选择会安全回落到「温柔陪伴」。
- DeepSeek 增加「不推荐，存在幻觉」提示。

## 权限与安全

- 修复「完全放行」在新建或切换对话后意外恢复为默认确认模式的问题。
- 「完全放行」仅在当前页面会话内有效，刷新或重新启动后仍回落到「每次确认」。
- 五分钟免确认模式会正确记录到期时间。
- 设备强度、脉冲、生命周期和紧急停止限制保持不变。

## 多设备

- 修复多台郊狼报告相同设备 ID 时被错误合并的问题。
- 连接多台郊狼时可明确选择 AI 当前控制的设备。
- 普通 AI 指令只发送到选中的郊狼；紧急停止仍覆盖全部已连接设备。
- 不存在或已经断开的目标会拒绝执行，不会静默切换到其他设备。

## 交付

- Web：与本版本同步部署。
- Android：`0xnuller-v6.0.14.apk`。
- 统一产品标签：`v6.0.14`。
