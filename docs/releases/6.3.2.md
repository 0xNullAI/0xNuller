# 0xNuller 6.3.2

本版本完成 6.3 系列的代码整理，并显著精简开发测试。

## 测试与维护

- 测试用例由 1534 个精简为 673 个，删除重复的实现细节、界面文案和跨层重复覆盖。
- 保留设备身份、多设备精确路由、权限、安全上限、租约、停止与紧急停止、认证和数据完整性等关键回归测试。
- 日常测试统一为 `npm test`，完整验证使用 `npm run test:full`，移除多余的测试分层脚本。
- 清理只供已删除测试使用的依赖，并同步简化开发文档与 `AGENTS.md`。

## 版本

- Web 与 Android 使用统一版本 `6.3.2`，Android 内部版本号为 `6003002`。
- Android APK：`0xnuller-v6.3.2.apk`。
