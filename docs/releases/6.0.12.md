# 0xNuller 6.0.12

这是一次 Coyote 2.0 协议兼容性补丁发布，网页端与 Android 端使用同一版本。

## 修复

- 修复 Coyote 2.0 强度特征（1504）和双通道波形特征（1505/1506）的 3 字节数据包字节序；现在按照设备要求使用小端格式发送。
- 强度通知同步改为小端解析，避免单通道几乎无输出以及双通道强度异常升高。
- 保持设备的交叉通道映射：A 通道波形写入 1506，B 通道波形写入 1505。

## 开发者交付

- DG-Kit 固定版本组升级至 `1.16.2`。
- DG-MCP 升级至 `1.2.3`，最低依赖 DG-Kit `1.16.2`，CLI 与 MCP 初始化信息统一报告包版本。
- npm 发布流程现在保证 DG-MCP 等待其 DG-Kit 依赖可从 npm 安装后再发布。

## 验证

- 全仓 158 个测试文件、1237 个测试通过。
- 结构检查、Lint、类型检查、MCP/Kit 发布包验证和全仓构建通过。
- Coyote 2.0 真机验证：单通道输出恢复正常，双通道不再异常升至接近满功率。

## 交付

- Web：与本版本同步部署。
- Android：`0xnuller-v6.0.12.apk`。
- 统一产品标签：`v6.0.12`。
