# 0xNuller 6.5.0

6.5.0 将平台模型从临时体验升级为使用 Credit 的正式服务，并完成账户、交友与个人主页的一轮整理。

- Agent、Chat 和 Video 默认使用 0xNullAI 托管模型，按实际用量结算 Credit；自己的 API、第三方 OpenAI 兼容地址和高级连接设置继续保留。
- Voice 使用同一账户余额，按 10 秒计费；连接失败释放预留额度。旧的文本与语音免费日额度已移除。
- 账户页显示余额和账本记录；邀请成功奖励 500 Credit；后台支持固定人民币档位的人工确认入账和不可重复流水。
- 交友与个人主页改为完整页面，增加主动发现、兴趣和城市资料、好友可见范围、黑名单、举报以及受鉴权的相册。
- Cloudflare Worker 公开入口、日志和旁路配置由仓库统一管理；桌面构建继续提供 Windows x64 与 Apple Silicon macOS，另提供 Android APK。

这是不兼容更新：旧的 `free`/`trial` 服务入口会迁移到新的托管服务，不再提供免费回退。
