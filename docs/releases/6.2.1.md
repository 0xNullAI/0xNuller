# 0xNuller 6.2.1

本版本简化设置与 Video 使用流程，并修复摄像头、AI 网络代理和设备授权生命周期问题。

## 设置与导航

- “外观”设置更名为“通用”。
- Agent、Voice 和 Video 现在共用“通用”中的 AI 网络代理；切换代理后，后续请求立即使用新地址。
- 实验性通用设备开关仅保留在“设置 → 关于”，默认关闭。
- Control 仅在用户主动开启实验功能后显示通用设备面板。
- 主导航调整为 Control、Chat、Agent、Voice、Video、Market、Playground。
- Video 凭据字段统一显示为“API 密钥”。

## Video

- 进入 Video 后先完成摄像头、物理目标、通道、强度上限、增强能力、时长和观察节奏设置。
- 开启后只显示一个居中的最新处理画面，固定为 16:9、最长边 768 px，并每秒采集。
- 摄像头预览不再依赖视觉模型或 API 密钥配置。
- 修复网页版摄像头无法正常开启，以及停止后迟到画面或权限回调恢复旧状态的问题。

## 安全与稳定性

- 紧急停止、结束、摄像头中断、页面隐藏、模块卸载和设备租约丢失会使待处理授权立即失效。
- 迟到的授权结果不能清除更新的紧急停止锁，也不能重新启动设备控制。
- 暂停后必须先确认设备已停止，才能继续运行。
- 图片仍仅作为当前推理的临时输入，不进入会话历史、浏览器存储、账户同步、导出、trace 或日志。

## 交付

- Web 与 Android 使用统一版本 `6.2.1`。
- Android 内部版本号为 `6002001`。
- Android APK：`0xnuller-v6.2.1.apk`。
