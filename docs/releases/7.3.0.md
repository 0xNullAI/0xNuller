# 猫愿 7.3.0

这一版更新了安卓原生层，需要安装新的安装包；网页版刷新即可。安卓上 7.2.0 没有单独的安装包，
它的全部内容都包含在这一版里（见 [7.2.0 说明](7.2.0.md)：卡密兑换、设备安全底线、加密存储等）。

## 安卓：切到后台可以保持输出

- 「设备与安全 → 切到后台时」在安卓上可选保持当前输出 5 或 10 分钟（网页版仍可选 30 分钟）。默认仍是立即停止。
- 开启后，设备输出时通知栏会常驻「设备输出中」，切到后台后显示剩余时间，并有「急停」按钮。急停不经过页面，页面卡住也能停。
- 保持期间只能停止或降低强度，AI 暂停；到时、在最近任务里划掉应用、或系统结束服务时都会自动停止。
- 需要允许通知；不允许时仍按立即停止处理。
- 部分手机会在后台强行结束应用，这时只能依靠设备里写入的强度上限。开启前请在系统设置里允许猫愿后台运行。

## 其他

- 安卓检查新版本时先读本站的版本信息，不再依赖 GitHub 接口是否可用；安装包仍从 GitHub 下载。
- 群聊发语音时麦克风被拒绝，会提示原因并提供「去设置」。
