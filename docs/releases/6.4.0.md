# 0xNuller 6.4.0

本版本集中修复设备控制、实时通信和账户同步的边界问题，并整理生产部署与 CI 配置。

## 设备与实时功能

- Video 在授权或模型调用期间到期时不再继续执行设备指令；切换目标前确认旧设备已停止，拒绝结果也不会被误报为成功。
- Video 暂停和恢复视觉会话时保留拍摄请求，纯摄像头预览持续刷新；恢复前重新确认设备租约、授权和剩余时长。
- Voice 远端断线、连接中取消和组件退出都会关闭待连接会话、麦克风、播放和设备输出，避免后台残留。
- Chat 发送失败时保留输入内容，媒体上传和房间发送错误会明确反馈；录音初始化失败或退出页面时释放麦克风。
- Agent 与 Chat 支持中文输入法组合输入，按回车选字时不会误发送消息。

## 数据一致性

- 场景与波形同步不会再用慢到达的远端旧数据覆盖同步期间的本地编辑。
- 登录账户在拉取期间发生变化时，会丢弃旧账户结果并自动为新账户重新同步。

## 部署与 CI

- `llm.0xnullai.com` custom domain 纳入 Wrangler 配置，LLM Proxy 开启完整可观测性。
- 所有共享生产 Worker 关闭 workers.dev 和 Preview URL，避免绕过主域安全策略。
- CI 统一受影响测试入口，并只在桌面相关源码变化时构建 Windows x64 与 macOS Apple Silicon 安装包。
- DG-Kit 与 DG-MCP 合并为一个 npm 发布工作流，按 Kit 后 MCP 的依赖顺序发布。
- 发布工作流删除旧 Token 名称兼容层，只接受按生产用途区分的新名称。

## 界面

- 统一 Shell 保持固定侧边栏导航；Agent 会话、多设备状态和模块操作使用同一布局，不增加说明性弹窗或冗余文案。
- 网页“下载客户端”统一进入 GitHub 最新 Release 页面，可选择 Android、Windows 或 macOS 安装包。

## 版本与附件

- 统一产品版本 `6.4.0`，Android 内部版本号 `6004000`。
- Android：`0xnuller-v6.4.0.apk`。
- Windows：`0xnuller-v6.4.0-windows-x64.exe`。
- macOS：`0xnuller-v6.4.0-macos-arm64.dmg`。
