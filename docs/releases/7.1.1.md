# 猫愿 7.1.1

群 AI 改为归属于把它带进群的人。这一版只更新界面和服务器，安卓会通过热更新自动送达，不需要重新安装。

## 群 AI

- 每个成员都可以把自己的一个角色带进群（每群最多 3 个），群里显示为「名字 · 某某的 AI」。
- 任何成员都可以 @ 它；回复使用带它进群那个人的 Credit，与谁 @ 无关。主人可以设置它在本群的每日 Credit 上限。
- 主人可以随时撤出自己的 AI，群主可以移出任何 AI；主人退群后，他的 AI 也会离开。
- 群 AI 统一使用平台模型；自己的 API Key 只用于自己的一对一聊天。
- 以前群主设置的群 AI 会自动归到群主名下，以后由群主的 Credit 支付。
- 群 AI 暂时只聊天，不控制设备；「也允许群 AI 控制」开关已移除。

## 设备控制

- 成员卡片会显示「未授权控制」：对方还没有允许这个聊天控制设备时，你能直接看到，而不是点了没反应。停止操作始终有效。
