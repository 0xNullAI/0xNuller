# 0xNuller 6.3.5

本版本完成统一产品切换后的兼容层收尾，减少旧迁移代码与 Cloudflare 历史入口。

## 平台整理

- 移除主站的跨域 localStorage/IndexedDB 自动搬运引导；canonical 账户、Market 与 Chat 数据继续由现役 Cloudflare 存储维护。
- 移除 Chat 内部兼容包装和 Control 已废弃的界面组合，降低重复状态与后续维护成本。
- 历史 `agent`、`chat`、`voice`、`market`、`wiki` 独立子域正式下线，只保留统一主站与当前 API 服务。
- 退役浏览器迁移与旧域兼容 Worker；不删除现役 D1、R2 或 Durable Object 数据。

## 版本

- Web 与 Android 使用统一版本 `6.3.5`，Android 内部版本号为 `6003005`。
- Android APK：`0xnuller-v6.3.5.apk`。
