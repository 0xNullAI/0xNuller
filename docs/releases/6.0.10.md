# 0xNuller 6.0.10

这是一次 Android 蓝牙连接与设备控制稳定性补丁发布，网页端与 Android 端使用同一版本。

## 修复

- Android 11 与 Android 12+ 分别使用正确的蓝牙扫描与权限路径，并补齐蓝牙、定位和权限状态提示。
- 内置设备选择弹窗只展示经过名称或 GATT 服务验证的 DG-Lab 设备，避免附近无关 BLE 广播误导用户。
- 支持 Android/MIUI 上不广播本地名称的郊狼，通过完整服务指纹识别设备型号。
- 串行执行匿名设备验证，并在正式连接前关闭临时 GATT 探测，减少 Android GATT 133 连接冲突。
- 修复郊狼连接后的协议初始化、通知订阅与控制写入；真机验证低强度输出、归零和后台安全路径。
- 简化并统一郊狼与负鼠控制面板，保持每台设备独立的通道、波形队列和播放状态。
- 补充负鼠内置振动波形，并修复一次播放后停止、双通道选择和波形映射问题。
- 优化移动端设备弹窗、控制面板尺寸、安全区域和旧式导航栏遮挡。

## 交付
