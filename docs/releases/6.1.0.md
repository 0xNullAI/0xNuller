# 0xNuller 6.1.0

本版本新增独立 Video 模块，并加强设备急停、视觉隐私和物理目标授权边界。

## Video

- 新增独立 Video 工作区，与 Agent、Voice 分别使用各自的 AI Provider、凭据、模型、Prompt 和会话。
- 支持前后摄像头、原始画面与模型输入双预览，以及镜像、旋转、明暗、对比度、锐化、裁剪和输出尺寸调整。
- 画面采用最新帧异步观察；模型判断与本地画面刷新互不阻塞，不建立图片队列。
- 图片仅作为当前推理的临时输入，不进入对话历史、浏览器存储、账户同步、导出或 trace。
- 摄像头关闭、页面隐藏、设备断开、授权到期、控制权丢失、watchdog 或连续模型失败都会停止闭环。

## 设备授权与安全

- Video 每次运行必须明确授权物理目标、通道、强度上限、增强、短时脉冲、持续时间和观察节奏。
- Web 支持连接多台郊狼，并以当前连接的不透明 ID 精确选择目标；断开或同名重连不会继承旧授权。
- Android 在无法证明多设备身份时限制为单个郊狼目标，每次连接生成新的临时 ID。
- 普通生命周期停止仅作用于授权目标；目标身份失效时升级为全局停止。
- 紧急停止覆盖全部已连接郊狼和负鼠；停止失败会保持安全锁定并明确报告。
- 加固 Agent 的 generation 抢占和设备执行门，阻止停止后的迟到推理或排队任务恢复输出。

## Market

- 加强场景导入校验，拒绝无效结构、空 Prompt、超长内容和重复 Market ID。
- 管理员内容页支持波形与场景分类，并在服务端分页前完成筛选。

## 交付

- Web 与 Android 使用统一版本 `6.1.0`。
- Android 内部版本号为 `6001000`。
