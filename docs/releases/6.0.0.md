# 0xNuller 6.0.0

0xNuller 将 Control、Agent、Voice、Chat、Playground 与 Market 合并为一个网页和一个
Android 应用，共享设备连接、安全限制、账户与内容库。

## 兼容性

- Android 保留原 DG-Agent 的 applicationId 与签名身份，因此 5.x 用户可以原地升级；
  应用名称与产品版本从本版起统一为 0xNuller 6.0.0。
- `@dg-agent/*` 与 `@dg-kit/*` 是现有代码和 npm API 的兼容包名，不代表仍需安装多个应用。
- Android Release tag 必须是 `android-v6.0.0`；平台源码 Release tag 是 `v6.0.0`，两者
  承载的产物不同。

## 发布前检查

- `npm run verify:release`、`npm run lint`、`npm run typecheck`、`npm run test`、
  `npm run build` 全部通过。
- 从 `main` 的目标 commit 构建 APK，并用 `aapt` 核对 versionName/versionCode、用
  `apksigner` 核对旧 DG-Agent 证书。
- 在真机验证多设备连接与重连、全部设备急停、锁屏/后台自动停止、登录、体验版语音和
  更新提示。
- Cloudflare migrations、bindings、routes 和永不轮换的共享 secrets 已由发布人员在
  目标账户核对；任何 secret 都不得写入构建日志或 Release notes。

具体命令和回滚边界见 [`../android-release.md`](../android-release.md) 与
[`../deploy.md`](../deploy.md)。
