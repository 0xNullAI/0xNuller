# 0xNuller 6.0.0

0xNuller 6.0 将 Control、Agent、Voice、Chat、Playground 与 Market 合并为一个网页和
一个 Android 应用。

## 主要更新

- 统一顶部设备栏，一处连接后可在各模块间继续使用。
- 统一设置、主题、弹窗、移动端布局和设备安全限制。
- Control 支持多设备、波形播放和折叠的一键开火。
- Chat 加入账户登录、公开大厅、房间、私聊和联系人。
- Market 改为账户归属；上传者管理自己的内容，不再使用共享管理员口令。
- Agent 与 Voice 共用场景和设备状态。

## 兼容性

- Android 延续 DG-Agent 5.x 的升级身份，现有用户可以直接升级，数据无需重建。
- 旧版 Agent、Chat、Voice、Market 与 Wiki 网址在兼容期继续保留。
- 从本版起，产品名与版本号统一为 **0xNuller 6.0.0**。
