# 0xNuller 6.3.8

本版本修复长剧本粘贴时末尾丢失的问题，并包含此前 6.3.7 未成功发布的优化与桌面版本。

## 长剧本与发布修复

- 剧本、多人背景和角色描述不再通过 maxlength 静默截断粘贴文本；超出既有限制时保留全文并明确拒绝保存。
- 手动上传单人剧本保留开头与结尾空白，复制 JSON 保留完整字符和转义内容，复制失败提供下载提示。
- 修复 Android 编译引用桌面专用生命周期函数的问题。6.3.7 因此编译失败，未完成公开发布。

## 桌面版本

- Windows 10/11 x64 安装器，蓝牙使用 WinRT；macOS 13.3+ Apple Silicon 安装包，蓝牙使用 CoreBluetooth。
- 桌面窗口切后台撤销设备控制权；正常退出先等待停止确认，失败保留窗口。
- Windows/macOS 安装包与 Web、Android 来自同一 main 提交。
- 桌面安装包暂未配置 Windows Authenticode、Apple Developer ID 签名及公证；系统可能显示未验证开发者提示。实体蓝牙与锁屏行为仍需目标系统验收。

## 修复与优化

- 首屏必需 JavaScript gzip 体积减少约 55%；设置和弹窗按需加载。
- 修复隐藏游戏拦截其他模块键盘输入；离开游戏暂停，返回需主动继续。
- 设备停止提示等待真实结果，旧模块加载失败后的刷新也需先确认停止。
- 模型日志改用 IndexedDB，限制容量、增量写入，并修复尚未读取历史时清空日志遗漏。
- 普通偏好保存失败提供会话内回退与提醒，不降低安全设置保护。
- 改进窄屏导航焦点、紧急停止入口及浅色主题文字对比度。
- 明确现代浏览器/WebView 要求，旧环境显示升级提示，避免启动白屏及循环刷新。
- 更新依赖锁文件与部署、构建说明。

- Windows：`0xnuller-v6.3.8-windows-x64.exe`。
- macOS：`0xnuller-v6.3.8-macos-arm64.dmg`。
