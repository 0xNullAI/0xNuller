## 原创精选模板

`packages/platform/scenes/src/character-templates.ts` 现提供六种互补方向；均为本项目原创内容，按仓库 MIT 许可提供，非竞品导入、非真人扮演。

| 模板 | 核心体验                                 | 长期关系验收方向                                 |
| ---- | ---------------------------------------- | ------------------------------------------------ |
| 小岚 | 日常倾听、轻松复盘，不抢话、不直接下结论 | 用户称呼、日常事件跟进、纠正错误记忆             |
| 阿屿 | 生活探索、摄影、将想法拆成小计划         | 兴趣变化、计划进度、只有工具确认后才说已设置提醒 |
| 墨墨 | 共创故事与世界观                         | 作品设定与现实用户事实分离，群聊协作不泄露私聊   |
| 青禾 | 学习陪伴、拆解难题与合理休息             | 学习目标和进度可纠正，不把推测写成已确认事实     |
| 声声 | 日常音乐话题与心情交流                   | 跨文字/语音保持表达习惯，不假装听过未提供的歌曲  |
| 言之 | 难开口的话与虚构对话练习                 | 区分练习对象与真实联系人，不代替用户发送消息     |

Market「发现」页始终显示可展开的原创精选入口，六张模板与用户发布的 UGC 分开；登录后选中模板进入同一个页面式在线编辑器，修改并明确发布后才进入公开目录。原场景库入口仍兼容。Agent 与 Voice 继续读取同一 SavedScene.prompt；不改变已有内置场景、Market 管理界面或设备连接。模板只是提示词与公开卡片元数据，不会自行开启长期记忆、定时消息或设备权限。模板内容尚未通过真实模型的长期效果评测。

## 卡片、关系与记忆边界

公开 `CharacterCard` v1 保存简介、性格、开场、对话示例、标签、作者和许可。`SavedScene` 的 `characterCard` 为可选字段，旧 prompt/icon 数据保持兼容；本地读取、账户内容同步和 Market 场景导入保留合法元数据。Market 的公开头像由独立图片 ID 引用，私人头像仍属于用户实体。当前正文仍是实际对话设定的权威来源；元数据用于后续结构化编辑器，不自动覆盖用户编辑的正文。

用户给 AI 的专属名字、希望被称呼的名字、朋友与关系、共同事件、长期记忆属于服务器上的个人关系内容，以账户和角色实例隔离，不能写入公开卡片或随 Market 发布。公开角色更新必须保留用户的专属关系 ID，不用显示名称当外键。真人群聊只能获得该群明确共享的上下文；私人记忆检索必须在服务端权限边界过滤，不能只靠提示词约束。

本次公共卡片解析器对白名单字段与长度校验，排除未知的 memory/relationship 字段。它不是隐私内容识别器，不能阻止用户主动把个人文字粘到公开简介。发布前仍需明确预览发布字段。

## 后续编辑与发布

1. 在已有场景编辑器逐步增加结构化字段，保留完整 prompt 编辑和旧卡；编辑结构化字段时明确预览生成的 prompt，避免双份正文漂移。
2. 复用 Market 的登录归属、作者编辑、删除和管理员隐藏／恢复，增加角色分类、版本、来源和许可。Market Worker 已校验公开卡白名单字段并保存版本；真实账号发布和预发环境审核仍待验收。
3. CCv2/CCv3 JSON 及 PNG/CHARX 中的人物数据导入保留原始 JSON 对象与未知扩展，显示不支持字段；发布原件需明确勾选。运行时只读取允许的人物语义，设备授权、系统提示和工具策略永远不由角色卡替换。PNG/APNG 和 CHARX 原容器由作者账号私有保存、跨端可原样下载，不随公开卡发布；编辑后重生成完整容器、公开附属资产及真实第三方样本的完整往返测试尚待完成。
4. 质量评审包括首聊、十轮风格一致性、事实纠错、关系称呼、群聊边界、语音自然程度和记忆失效后的诚实回应。尚未完成真实模型对话评测，不能把模板称为效果已验证。
5. 创作者激励仅为站内 credit，可继续消费 AI；不设计提现、银行卡或现金结算。
