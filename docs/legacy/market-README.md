# DG-Market（旧版存档）

这是独立 DG-Market 项目的历史说明存档。旧站继续保留在
[market.0xnullai.com](https://market.0xnullai.com)，但不再单独维护。

当前 Market 已并入 0xNuller：

- 上传需要登录账户；
- 内容自动归属上传账户；
- 所有者可编辑、删除自己的内容；
- 管理员权限绑定到账户角色；
- 不再使用共享管理员口令或单条内容编辑口令。

当前开发、数据结构和部署说明请查看：

- [Market 模块说明](../../apps/market/README.md)
- [统一部署说明](../deploy.md)

旧数据库中的编辑凭证字段仅为无损迁移而保留，不参与新版本的产品流程。
