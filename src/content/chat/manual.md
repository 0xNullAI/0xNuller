# DG-Chat · 使用手册

自带郊狼控制功能的多人 P2P 房间，无需服务器。

> [GitHub](https://github.com/0xNullAI/DG-Chat) · [在线 demo](https://chat.0xnullai.com)

## 这是什么

DG-Chat 是浏览器端的多人聊天房间。聊天本身用 P2P 协议直连，无需服务器存储；除此之外，**每个成员可以把自己的郊狼设备授权给房间里其他人远程控制**——发"现在让谁谁谁来"，对方点你头像就能调强度、换波形、发短脉冲。

打开网页就能用，部署在 Cloudflare 的 HTTPS 上。聊天与设备控制流量都不经过任何中转服务器。

## 浏览器要求

跟 [DG-Agent](#/agent/manual) 一样：Chrome / Edge（桌面 + Android）、Bluefy（iOS）、Kiwi Browser（鸿蒙）。Safari / Firefox 不支持 Web Bluetooth。

## 三步上手

### 1. 创建或加入房间

打开 [demo](https://chat.0xnullai.com) → 输入昵称 → 选择：

- **创建房间**：系统生成房间号，分享给朋友
- **加入房间**：粘贴朋友给你的房间号，点加入

成功后跳到房间界面：左边是聊天面板，右边是成员列表。

### 2. 邀请朋友

房间号顶部有 **二维码** 按钮——展开后让朋友扫码或复制房间号。链接形式 `https://chat.0xnullai.com/?room=XXXX` 直接打开就进。

### 3. 连接郊狼（可选）

只想聊天不带设备也可以。要带设备：

1. 长按郊狼电源键开机
2. 点页面顶部蓝牙按钮（必须用户主动点，不会被消息触发）
3. 系统弹窗里选你的设备

成功后你的成员卡片会显示「设备已连接」标识，且**强度滑块、波形选择、安全上限都对所有成员可见**。

## 远程控制流程

### 你想被控制

1. 连接好设备（上一步）
2. 在聊天里告诉队友：「现在你来调」
3. 队友点你的成员卡片 → 进入控制界面

### 你想控制别人

1. 队友连好设备
2. 点对方成员卡片 → 进入对方控制界面
3. 调强度滑块、选波形、设安全上限——全部实时同步过去

> **本机端开了某个上限，远端控制不能突破**——这是协议层强制约束（`@dg-kit/protocol` 的 `setLimits()` 直接落到设备 BF 包），不是 UI 的礼貌提示。

## 安全上限：必读

每个通道有两个数字：

| 名字 | 范围 | 含义 |
|---|---|---|
| **当前强度** | 0–200 | 设备此刻的输出值 |
| **安全上限** | 0–200 | 强度滑块能拖到的最大值 |

打开 DG-Chat 默认每通道上限 = 50（保守值）。在控制界面可以拖动「上限滑块」修改：

- **降低上限** → 立即把当前强度也钳到新上限以内（不会突然加大）
- **提升上限** → 当前强度不变，只是允许将来拖更高

**远程控制者也能看到并修改你的上限**。如果你不希望别人改，可以聊天里说一声，或者直接断开蓝牙离开房间。

## 波形库

每个客户端有自己的波形库，**包括 6 个内置波形 + 自定义导入**。

### 内置（跟 DG-Agent 一样）

`breath` 呼吸 / `tide` 潮汐 / `pulse_low` 低脉冲 / `pulse_mid` 中脉冲 / `pulse_high` 高脉冲 / `tap` 敲击

### 导入第三方波形

右下角浮动按钮 **波形库** → 点「导入」→ 选 `.pulse` 或 `.zip`（Dungeonlab 格式）。波形保存到你浏览器 `localStorage`，**只对你可见**。

### 从 DG-Market 市场导入波形

除了导入本地文件，还可以在波形库里 **从 [DG-Market](https://market.0xnullai.com) 市场导入波形**：搜索市场上的波形 → 一键导入到本地波形库。导入后的波形跟本地波形一样保存在你浏览器 `localStorage`，**只对你可见**。

> **波形不会自动同步到其他成员**。如果你想让某个朋友用你导入的波形控制你，可以先选好那个波形再交出控制权。

## 后台行为

桌面用户切到其他标签页/窗口时，浏览器可能会节流计时器，影响波形输出。设置中有一个开关：

| 模式 | 行为 |
|---|---|
| **后台时停止输出** (默认) | 切到后台 → 强度归零、波形停止 |
| **后台时保持输出** | 切到后台 → 继续输出（基于 Web Worker 抗节流） |

第一次用建议选「停止」，更安全。等你确认稳定再考虑「保持」。

## 房间隐私

| 项目 | 是否经过服务器 |
|---|---|
| **聊天消息** | ❌ P2P 直连（PeerJS / WebRTC） |
| **设备命令** | ❌ P2P 直连 |
| **波形数据传输** | ❌ P2P 直连（如果有人想分享自己的波形给别人，会通过 P2P 数据通道） |
| **房间发现 (signaling)** | ✅ PeerJS 公共 signaling server，仅用于建立连接，不存储任何内容 |

聊天记录、设备状态、强度值——**没有任何数据落到服务器或作者手里**。

## 跟 DG-Agent 一起用

不行——同一时间设备只能被一个浏览器/进程连接。

但你可以：

1. **场景 A**：自己在 DG-Agent 里跟 AI 玩 → 临时切到 DG-Chat 让朋友远程操作 → 玩完再切回
2. **场景 B**：用两台设备，一台跑 DG-Agent，另一台跑 DG-Chat
3. **场景 C**：让 DG-Agent 的桥接器接 QQ/Telegram，朋友在 IM 里远程发指令（不需要 DG-Chat）

## 协议关系

DG-Chat 里有两个「协议」，容易混：

| 名字 | 是什么 |
|---|---|
| `lib/protocol.ts` | **P2P 消息协议**：聊天消息、设备命令、波形传输的数据形状 |
| `@dg-kit/protocol` | **BLE 协议**：郊狼 V2 / V3 蓝牙字节包打包 |

它们没关系。前者是 DG-Chat 自己的房间消息格式，后者来自中台。
