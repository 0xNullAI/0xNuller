# DG-Wiki

四个项目的统一文档与使用手册。点左侧任一条目跳转，或继续往下读了解 DG 系列大致是什么。

## 这是什么

DG-Wiki 是 **DG-Lab 郊狼 2.0 / 3.0** 周边四个开源项目的中央文档站：

| 项目 | 我是用户，应该看哪里 |
|---|---|
| [DG-Agent](#/agent) | 你想用 AI 在浏览器里直接控制设备 |
| [DG-Chat](#/chat) | 你想跟队友联机，让对方远程控制你的设备 |
| [DG-MCP](#/mcp) | 你已经在用 Claude Desktop，想让它直接接设备 |
| [DG-Kit](#/kit) | 你是开发者，想了解协议细节或者基于这套架构做二开 |

## 我应该用哪一个？

下面这张表帮你 30 秒选择：

| 你的场景 | 推荐 | 备注 |
|---|---|---|
| 单人，想要 AI 引导式体验 | [DG-Agent](#/agent) | 完整 LLM 工具调用，最丰富 |
| 双人/多人，远程互动 | [DG-Chat](#/chat) | P2P，无服务器 |
| 已有 Claude Desktop / Cursor / Cline | [DG-MCP](#/mcp) | 一行 npx 命令搞定 |
| 自己想魔改某个项目 | 先看 [DG-Kit](#/kit) | 理解中台再动手 |

不冲突，三个工具可以混着用——但**同一台设备同一时间只能被一处连接**。

## 入门时间线

如果你**第一次**接触 DG 系列：

1. **先读** [DG-Agent 使用手册](#/agent) → 理解 LLM 工具调用、强度上限、安全约束这些核心概念
2. **再上手**：跑通 demo（[在线版本](https://0xnullai.github.io/DG-Agent/)），熟悉 1-2 个波形
3. **想联机** → 看 [DG-Chat](#/chat)；**想接 Claude Desktop** → 看 [DG-MCP](#/mcp)
4. **遇到问题** → 每个项目页都有「常见问题」和「故障排查」小节

## 安全声明

> 强度量程 0–200。冷启动工具默认钳制初始强度 ≤10。**第一次用先把通道安全上限调到 30 以下**，等熟悉了再放开。任何时候说「停一下/紧急停止/关掉」AI 都会立即响应；也可以直接断开蓝牙连接。

设备的物理拨轮可以独立加强度——软件端的「上限」不是绝对天花板。佩戴位置请参考 DG-Lab 官方说明。

## 设计理念

- **一份代码，三个产品**。蓝牙协议、波形数据、工具定义只在 [DG-Kit](#/kit) 维护，三个产品共享同一个实现。
- **传输无关**。同一份协议代码能在浏览器跑，也能在 Node 跑。
- **完全本地**。会话、波形库、设置全部在浏览器或本机进程，不上传、不走服务器、不收集任何数据。
- **安全在协议层**。强度上限、冷启动钳制、紧急停止、回合限速 —— 这些约束嵌在中台代码里，UI / LLM 都绕不过。

## 在线编辑这份文档
