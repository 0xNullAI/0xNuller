# DG-Agent · FAQ / 故障排查

## 常见问题

### 连不上设备

- 浏览器是 Chrome / Edge（或 iOS 上的 Bluefy）？
- URL 是 HTTPS 或 `localhost`？http 不允许 Web Bluetooth
- 设备是否已被其他设备/程序连着？同一时间只能连一处
- 长按电源键，等指示灯稳定再点蓝牙

### AI 不响应 / 工具不调用

- 检查 LLM provider API key 是否正确
- 网络是否能访问该 provider 的端点（国内访问 OpenAI 需要科学上网）
- 模型名是否填对（OpenAI 推荐 `gpt-4o-mini` 起步，太弱的模型不会主动工具调用）
- 看浏览器 DevTools 控制台有无报错

### 调强度没反应

- 通道是否已启动？没启动状态下 `adjust_strength` 没意义，AI 会先 `start`
- 是否撞到了软上限？看顶部状态条
- 设备物理拨轮的位置会与软件叠加，调到最低再操作

### 换浏览器 / 设备会丢数据吗

- 会丢。所有数据（API key、会话历史、波形库、设置）只在当前浏览器的 `localStorage` / `IndexedDB`
- 想跨浏览器迁移：手动复制对应的 IndexedDB / localStorage 数据；或者就重新配置一遍

### 可以多设备多浏览器同时控制吗

- 不行，蓝牙连接是排他的
- 想让多人远程操控你的设备，去 [DG-Chat](#/chat/manual)

### 电量怎么显示？

- 顶部状态条会读 GATT 电池服务，连接时同步一次
- 长时间未刷新可能滞后

### LLM 反复"思考"很慢

- 模型推理慢，换更快的（DeepSeek、Qwen-Turbo、Claude Haiku）
- 减少上下文：「设置 → 模型上下文策略」改成 `last-user-turn`
- 网络慢：免费体验模式有限速，换自己的 API key

### 桥接消息没收到

- NapCat / Telegram bot 是否在线？
- WebSocket URL 后面是否带了 `?access_token=xxx`（NapCat）
- DG-Agent 设置的桥接是否启用了？看右上角标志
- 群里 @机器人才会触发，私聊或非 @ 默认忽略

### 桥接消息能控制设备吗？

- 默认能。安全设置里可以关闭"桥接消息允许工具调用"开关——开关关了之后，桥接来的消息只能聊天不能操作
- 桥接消息和你自己的消息共享会话上下文，群友能看到你之前的对话

### iOS 怎么用？

- App Store 装 [Bluefy](https://apps.apple.com/app/bluefy-web-ble-browser/id1492822055)
- 在 Bluefy 里打开 https://0xnullai.github.io/DG-Agent/
- Safari 不支持 Web Bluetooth，无解

### 后台标签页输出停了

- Chrome 的标签页节流策略：后台标签页计时器会被降频甚至挂起
- DG-Agent 用 Web Worker 模拟独立 tick，理论上抗节流，但极端情况仍可能卡顿
- 设置 → "后台行为" 里可以选「切到后台时停止输出」（更安全）

## 故障排查

```
症状                       → 排查方向
─────────────────────────────────────────────
点蓝牙按钮无反应             → 浏览器不支持，换 Chrome/Edge
弹窗里看不到设备             → 设备没开机 / 已被其它客户端占用
连接失败、断开重连           → 距离太远 / 干扰；尝试重启设备
工具调用一直转圈             → LLM 端超时，换 provider 或检查网络
强度已到上限，AI 还想加       → 安全设置里手动放开上限
后台标签页输出停了           → 浏览器节流；切回前台或调「后台行为」
LLM 不停问问题不调工具       → system prompt 没引导住；换更强的模型
换波形要用 start 而不是 change → AI 没意识到通道已启动；告诉它「不用启动，只换」
```

## 调试技巧

打开浏览器 DevTools → Console，DG-Agent 会输出：

- LLM 请求 / 响应（开发者模式开启时）
- 工具调用 / 拒绝原因
- 蓝牙连接 / 断开事件
- 桥接消息

如果遇到 bug 想给作者反馈，附上 console 截图最有用。

## 隐私问题

### DG-Agent 会上传我的数据吗？

不会。具体见 [使用手册的隐私说明](#/agent/manual)。

### 我用「免费体验」会被记录吗？

会有 7 天的调用日志保留（用于排错），不会读你具体说什么但会记录调用次数 / 时间。介意请用自己的 API key。

### 桥接的群消息会被作者看到吗？

不会。桥接消息走你自己的 NapCat / Telegram bot，作者不在中间。

## 故意设计的限制

下面这些不是 bug 而是有意为之：

- **冷启动强度 ≤ 10**：第一次给某通道供电时强度被钳制
- **adjust_strength 单步 ≤ 10**：避免 AI 一次拉太狠
- **每回合 burst ≤ 1 次**：避免连续猛击
- **每回合 design_wave ≤ 1 次**：避免 LLM 失控乱设计
- **timer 不会自动操作设备**：到期回合 AI 只能简短问候

如果你充分了解后果想放开：去「设置 → 安全设置」改。
