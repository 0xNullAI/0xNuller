# DG-Agent · 使用手册

用自然语言控制 DG-Lab 郊狼 2.0 / 3.0 的浏览器版 AI 控制器。

> [GitHub](https://github.com/0xNullAI/DG-Agent) · [在线 demo](https://0xnullai.github.io/DG-Agent/) · 交流 QQ 群 **628954471**

## 这是什么

打开网页、连上你的郊狼、跟 AI 对话——它会通过工具调用真正控制设备：调强度、换波形、设计新波形、定时跟进。

跟普通 chatbot 不一样的地方在于：AI 真的能"动手"。"启动 A 通道，强度 5，用呼吸波形" 这句话会被理解为一个工具调用序列，AI 自己安全地拆步执行，每一步都受策略引擎约束。

## 第一次使用：5 步上手

### 1. 打开页面

在线版：https://0xnullai.github.io/DG-Agent/

要本地跑：

```bash
git clone https://github.com/0xNullAI/DG-Agent.git
cd DG-Agent && npm install && npm run dev
```

打开 http://localhost:5173/。

### 2. 配置 LLM Provider

点右上角齿轮图标 → **模型配置** → 选一个 provider：

| Provider | 速度 | 成本 | 备注 |
|---|---|---|---|
| **免费体验** | 快 | 免费 | 走作者维护的代理，限速 |
| **OpenAI** | 快 | 付费 | gpt-4o / gpt-4-turbo 推荐 |
| **DeepSeek** | 快 | 便宜 | 国内可访问 |
| **Qwen / 通义千问** | 快 | 便宜 | 国内可访问 |
| **Anthropic** | 中 | 付费 | Claude 系列 |
| **任何 OpenAI 兼容服务** | — | — | 自定义 base URL |

填上 API key，选模型名，关掉抽屉。设置在抽屉关闭那一刻保存到浏览器。

> ⚠️ API key 完全保存在你浏览器的 `localStorage`，不会上传到任何地方。

### 3. 打开郊狼

长按主机电源键，听到提示音。等指示灯稳定。

### 4. 蓝牙连接

点页面**顶部蓝牙按钮**（不是 AI 自动触发，必须显式点击）→ 系统弹出蓝牙设备选择器 → 选你的郊狼（V3 名字以 `47L121` 开头，V2 是 `D-LAB ESTIM…`）→ 配对。

成功后顶部会显示设备状态条：电量、A/B 通道当前强度、上限。

### 5. 跟 AI 对话

输入框示例：

```
请用呼吸波形启动 A 通道，强度 5
```

AI 会描述意图、执行工具调用、设备开始输出，然后问你「感觉怎么样？」。继续对话调整即可：

```
A 通道再加一点，换中脉冲
B 通道也启动起来，潮汐波，强度 3
来个短脉冲
停下
```

## 工具详解（用户视角）

AI 通过下面这些工具控制设备。你不需要直接调用，但理解它们能帮你更精准地表达意图。

### `start` 启动通道

新启动一个通道，同时设置初始强度和波形。

- **触发**：通道当前停止，需要从零开始时
- **冷启动上限**：初始强度 ≤ 10（受安全设置约束）
- **示例话术**：「启动 A 通道，强度 5，用呼吸波形」

### `adjust_strength` 调节强度

在不改变波形的前提下相对调整强度（±10 / 步）。

- **触发**：通道运行中，需要小步推进或回落
- **每回合限制**：最多 2 次调用
- **示例话术**：「再加一点」/「调低一点」/「+5」

### `change_wave` 切换波形

不改变强度，仅换波形。

- **触发**：已启动后想换节奏、换触感
- **示例话术**：「换成潮汐」/「试试敲击」

### `burst` 短脉冲

把通道短暂拉到目标强度，持续一段时间后**自动回落**。

- **触发**：制造短促峰值、强烈点射感
- **每回合限制**：最多 1 次，单次时长 100-5000ms
- **示例话术**：「来个短脉冲」/「持续 2 秒猛击」

### `design_wave` 设计波形

用 `ramp / hold / pulse / silence` 四种段落组合一个新波形，**自动入库**。

- **触发**：已有波形不能表达你想要的体感
- **每回合限制**：1 次
- **示例话术**：「设计一个慢慢渐入然后突然敲击的波形」

新波形保存后会出现在波形选择列表，下次直接用名字调用。

### `stop` 停止

停止某通道或所有通道。

- **触发**：「停一下」/「够了」/「关掉」
- **示例话术**：直接说就行

### `timer` 定时器

让 AI 在 N 秒后主动跟进一次。

- **触发**：「2 分钟后再问我感觉」
- **限制**：到期回合是内部触发，AI 只会简短问候，**不会**自动操作设备

## 内置波形

| ID | 中文名 | 体感 |
|---|---|---|
| `breath` | 呼吸 | 渐强渐弱，最温柔的铺垫 |
| `tide` | 潮汐 | 波浪般起伏的慢节奏 |
| `pulse_low` | 低脉冲 | 轻柔的规律节奏 |
| `pulse_mid` | 中脉冲 | 中等强度规律节奏 |
| `pulse_high` | 高脉冲 | 强烈规律节奏 |
| `tap` | 敲击 | 带停顿的点触感 |

加上你导入的 `.pulse` 波形 + AI 设计的波形，全部都能在选择器里看到。

## 导入第三方波形

DG-Agent 支持导入 Dungeonlab 格式的 `.pulse` 文件（单文件或 `.zip` 包）：

1. 设置抽屉 → **波形库** → 点「导入」
2. 选 `.pulse` 或 `.zip`
3. 解析后波形入库，AI 立即可见

社区波形包搜索关键词：「DG-Lab pulse 波形」。

## 语音输入输出

设置抽屉 → **语音设置**：

| 模式 | ASR（语音→文字） | TTS（文字→语音） |
|---|---|---|
| **浏览器原生** | Web Speech API | SpeechSynthesis |
| **DashScope** | 阿里云通义千问 ASR | 阿里云 TTS |
| **关闭** | — | — |

DashScope 模式需要 API key（在阿里云控制台开通）。手机端推荐用 DashScope，浏览器原生在中文识别上准确率较低。

## 桥接 IM

让群友通过 QQ / Telegram 文字驱动你的设备。

### QQ（NapCat / OneBot）

1. 在你的服务器跑 [NapCat](https://github.com/NapNeko/NapCatQQ)
2. DG-Agent 设置 → **桥接** → 选 QQ → 填 WebSocket URL（带 `?access_token=xxx`）
3. 群里 @机器人发送指令，路由到本地 DG-Agent

### Telegram

1. 找 [@BotFather](https://t.me/botfather) 创建 bot，拿 token
2. 设置 → **桥接** → 选 Telegram → 填 token
3. 私聊或群聊 bot

> 桥接消息使用统一的 LLM 上下文，群友的话和你自己的话在 AI 看来是同一个会话。这意味着群友能看到你之前问 AI 的内容——慎用。

## 安全设置

设置抽屉 → **安全设置**，可以改：

- **冷启动强度上限**：默认 10，AI 第一次启动通道时的最高强度
- **单步调整幅度**：默认 ±10，每次 `adjust_strength` 不能超过这个值
- **每回合调用次数**：`adjust_strength` 默认 2 次，`burst` 默认 1 次
- **Burst 时长上限**：默认 5000ms

> 这些设置改了之后立即生效。**降低**上限是安全的；**提升**上限请充分了解后果。

## 推荐工作流

第一次：

1. 强度上限调到 30 以下
2. 让 AI 用呼吸波形启动 A 通道，强度 5
3. 跟 AI 反馈「感觉怎么样」，让它慢慢加强
4. 试试换波形：「换成潮汐」「换成低脉冲」
5. 觉得 OK 之后试试 burst：「来个 1 秒短脉冲」
6. 想休息：「停一下」

熟练之后：

- 让 AI 设计自定义波形
- 配桥接让群友互动
- 试 timer：「3 分钟后再来一波」

## 隐私说明

- **会话**：保存在浏览器 IndexedDB，不上传
- **波形库**：保存在浏览器 IndexedDB，不上传
