# 常见问题

## 连接设备

### 搜不到郊狼

把郊狼两侧的滚轮**同时向下按住 3–5 秒**，直到屏幕闪烁，进入配对模式，再点一次
「连接蓝牙」。

还是不行的话依次检查：

- **浏览器** —— 必须是 Chrome 或 Edge。Safari 和 Firefox 不支持网页蓝牙，请用安卓版。
- **地址** —— 必须是 HTTPS 或 localhost。普通 HTTP 页面用不了网页蓝牙。
- **权限** —— 安卓版需要蓝牙权限。拒绝过的话去系统设置里重新打开。
- **配对残留** —— 之前和别的设备配过，先在系统蓝牙里「忘记」这个设备。

### 连上了又断

多半是距离或电量。把手机放近一点，检查郊狼电量。

如果频繁断连，先在设置里把上限调低——断连重连的瞬间强度可能跳变。

## 使用中

### 停止按钮在哪

在内容区最上方那条设备栏的**最左边**，红色的。

**只有连着设备时才会出现**，没连设备时不显示是正常的。

如果连着设备却看不到它，请立刻长按郊狼电源键关机，然后反馈这个问题。

### 切换模块后别人控制不了我了

这是设计如此。你在看哪个模块，就只有那个模块能下指令。

切走 Chat 的瞬间，房间里其他人的指令全部失效，他们会看到你的设备变成不可控。
切回来就恢复。

### 在 Agent 里调的上限，Chat 里也变了

对，安全设置是全应用共享的一份。

这是刻意的：如果每个模块各存一份，你在一处调高、切到另一处又变回去，而且完全
没有提示——那比统一更危险。

### AI 不听我的

先看它有没有请求确认——默认每条设备指令都要你点「允许」。

如果是理解偏差，把话说得更具体：「A 通道调到 8」比「大一点」更可靠。

## 账号

### 一定要注册吗

不用。逛市场、进房间、用 Agent、用 Voice，全都不需要账号。

登录只带来跨设备同步（你的波形、场景、市场上传）。

### 忘记密码怎么办

找不回。注册时不要求邮箱，代价就是这个。

不介意重新开始的话可以注册新账号——你的波形、场景、设置都存在本机浏览器里，
跟账号无关，不会丢。

### 注销账号会真的删掉吗

会。是真删不是标记，所有设备上的登录立即失效，用户名释放出来可以被别人注册。

## 设置

### 免费体验有什么限制

由代理服务提供额度，有速率和总量上限。想要更强的模型或自己的额度，去
**软件设置 → AI** 换成自己的 provider。

### 代理里的 SOCKS 为什么是灰的

网页端做不到。浏览器不允许网页自己选代理——那是操作系统或浏览器的设置。

网页端能用的只有 HTTP 反代：把请求指向你自己的反代地址，由它转发。
SOCKS 只在安卓/桌面客户端里生效。

### 我的数据存在哪

- **波形、场景、设置、对话记录** —— 存在浏览器本地。清除站点数据会丢。
- **API Key** —— 也在本地，**不加密**。同源脚本和浏览器扩展都读得到。
  真正需要保密的话请自建代理，让密钥只留在服务端。
- **账号** —— 用户名和密码哈希在服务端。密码用 PBKDF2-SHA256，21 万轮。
