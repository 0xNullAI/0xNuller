# 常见问题

## 搜索不到设备

把郊狼两侧滚轮同时向下按住 3–5 秒进入蓝牙配对模式。另外确认：

- 浏览器支持 Web Bluetooth（Chrome / Edge。**Safari 和 Firefox 不支持**，用安卓版）。
- 页面是 HTTPS 或 localhost —— Web Bluetooth 不在普通 HTTP 页面上工作。
- 安卓版需要授予蓝牙权限。拒绝过的话去系统设置里改。

## 停止按钮不见了

它只在**有设备连着**时出现，在内容区顶部那条设备栏的最左边。没连设备时不显示是正常的。

如果连着设备却看不到，那是 bug，请立刻物理断开设备（长按郊狼电源键）并反馈。

## 切换模块后别人控制不了我的设备了

这是设计如此。切走一个模块就交出该模块的设备控制权——你在看哪个模块，就只有那个
模块能下指令。对方会看到「已离开房间，无法控制」。

## 我在 Agent 里调的上限，Chat 里为什么也变了

安全设置是全应用共享的一份，这是刻意的。合并前三个模块各存各的，用户在一处调高、
切到另一处又变回去，而变回去这件事没有任何提示——那比统一更危险。

## 需要注册吗

不需要。逛市场、进房间、用 Agent、用 Voice 全都不需要账号。

登录只带来跨设备同步（波形库、场景、市场归属）。它**不带来任何设备控制权**。

## 忘记密码怎么办

找不回。注册时不要求邮箱，代价就是这个——请自行妥善保存密码。

如果你不介意重新开始，可以注册一个新账号；本地数据（波形、场景、设置）都存在浏览器
里，不受账号影响。

## 数据存在哪

- **设置、波形、场景、会话**：存在浏览器本地（localStorage / IndexedDB）。清除站点
  数据会丢失。
- **API Key**：也在本地，**不加密**——同源脚本和浏览器扩展都读得到。真正需要保密的
  部署应该自建代理，让密钥只存在于服务端。
- **账号**：用户名与密码哈希存在服务端。密码用 PBKDF2-SHA256，210,000 轮。

## 注销账号会真的删掉吗

会。是硬删除不是标记，所有设备上的会话立即失效，用户名随之释放。

## 免费体验有什么限制

由代理服务提供额度，有速率与总量上限。想要更强的模型或自己的额度，在软件设置的 AI
页换成自己的 provider。

## 代理设置里的 SOCKS 为什么是灰的

网页端做不到。浏览器不允许页面自行选择代理——那是操作系统或浏览器层的设置，页面里
的 JavaScript 没有这个能力。

网页端能做的只有 HTTP 反代：把请求指向你自己的反代地址，由它转发。SOCKS 只在桌面/
安卓客户端里生效。
