# 快速开始

0xNuller 用来控制 DG-Lab 郊狼 2.0 / 3.0 及其配件（负鼠、爪印、灵狐）。四个模块共用
一套设备连接、一份安全设置和一个波形/场景库——**连一次设备，四处可用**。

## 五步上手

1. **打开应用。** 网页版直接访问，安卓版装 APK。不需要注册。
2. **打开郊狼。** 长按开机，确认蓝牙已开启。
3. **连接设备。** 在 Agent 里点「连接蓝牙」，或在任意模块的连接入口。首次连接会弹出
   一次使用前安全须知——请认真读完，那是这个软件唯一一次打断你。
4. **确认强度上限。** 侧边栏底部头像 → 软件设置 → 设备安全。默认 50（协议范围 0–200）。
   这个值是全应用共享的，任何来源都不能超过它。
5. **开始使用。** 选一个模块。

## 四个模块

| 模块 | 做什么 |
|---|---|
| **Agent** | 用自然语言跟 AI 对话，它通过工具调用真正控制设备：调强度、换波形、设计新波形、定时跟进。 |
| **Chat** | 多人房间。房间里的其他人可以在你设定的上限内控制你的设备。打开即进常驻公开房。 |
| **Voice** | 实时语音通话。说话就能控制，模型边说边操作。 |
| **Market** | 波形与场景社区。看到喜欢的一键导入自己的库，Agent 和 Voice 都能用。 |

## 需要知道的三件事

**不需要账号。** 账号只用来跨设备同步波形库、场景和市场归属。**登录不会带来任何设备
控制权**——控制权始终需要当面授予，且随时可以撤销。哪怕你在另一台设备上登录了同一个
账号，也不能远程控制你正在用的郊狼。

**切换模块会交出设备控制权。** 从 Chat 切到 Agent 时，房间里其他人的指令立刻失效，
对方会看到「已离开房间，无法控制」。这是刻意的：你在看哪个模块，就只有那个模块能
下指令。

**停止永远在一个动作之内。** 连上设备后，内容区顶部会出现一条设备栏，最左边就是停止
按钮。它不随你切换模块而消失，只要还有设备连着它就在。
