# Voice

实时语音通话。你说话，AI 边听边操作，比打字快得多。

## 怎么用

1. 点页面顶部统一设备横栏的「连接设备」，连接郊狼或负鼠
2. 点「开始通话」
3. 说话

挂断点挂断按钮。切到别的模块会自动挂断，这是正常的安全动作，不会显示成红色错误。

## 第一次要先配语音服务

**软件设置 → AI → 语音服务**。

可以填自己的 key（xAI / OpenAI / Azure / 智谱），也可以用**体验版**——体验版需要
激活密钥，有单次时长和每日总量上限。

音色和语速也在这一页，跟着 provider 走：换 provider 时它们会一起变，因为每家的
音色列表都不一样。

## 场景

和 Agent 共用同一个库。

内置人设在这里的说法是为**朗读**改写过的：句子更短，不会念出 markdown 符号。
你自己写的场景两边完全一样。

## 通话中的安全

跟打字时一样，上限在你自己的设备上执行。

通话中切换模块会挂断并交出设备控制权。
