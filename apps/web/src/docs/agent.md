# Agent

通过文字对话控制设备。

## 怎么用

1. 打开 **设备** 页，点击「连接设备」。
2. 选择场景。
3. 输入明确的操作要求。

例如：

> A 通道调到 8，保持两分钟

> 使用呼吸波形，强度 5

> 停止

涉及设备的操作会按当前确认设置执行。确认方式可在 **我的 → 设备安全** 中调整。

## 场景

场景用于设定对话风格。可以在场景选择器或 **我的 → 场景** 中管理。

## 对话

在 **消息** 页点击 **新聊天 → 与 AI 聊天** 新建会话，点击列表中的会话即可切换。

旧 DG-Agent 的对话不需要转换：先在旧版「设置 → 数据」导出 ZIP，再到当前版本的
「设置 → 数据 → 导入」选择该文件。也可以直接导入旧版 JSON。
