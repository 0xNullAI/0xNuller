# Agent

通过文字对话控制设备。

## 怎么用

1. 点击顶部横栏的「连接设备」。
2. 选择场景。
3. 输入明确的操作要求。

例如：

> A 通道调到 8，保持两分钟

> 使用呼吸波形，强度 5

> 停止

涉及设备的操作会按当前确认设置执行。确认方式可在 **软件设置 → 设备安全** 中调整。

## 场景

场景用于设定对话风格。可以在场景选择器或 **软件设置 → 场景** 中管理。

## 对话

侧边栏「对话」可新建、切换和管理会话。

旧 DG-Agent 的对话不需要转换：先在旧版「设置 → 数据」导出 ZIP，再到当前版本的
「设置 → 数据 → 导入」选择该文件。也可以直接导入旧版 JSON。

## 用 QQ 远程对话

Agent 可以通过本机运行的 [NapCat](https://github.com/NapNeko/NapCatQQ) 接收 QQ 消息。建议使用
单独的机器人账号；网页必须保持打开，设备也仍由当前网页连接和执行。

1. 在 NapCat 中添加 OneBot v11 **正向 WebSocket**，默认监听 `3001`，并关闭「上报自身消息」。
2. 打开 **软件设置 → Agent → 桥接**，启用 QQ。
3. 填写 WebSocket 地址（通常是 `ws://localhost:3001`）以及允许控制的 QQ 用户号或群号。
4. 选择权限模式并保存。群聊中需要 `@机器人` 才会触发 Agent。

连接失败时，先确认 NapCat 和 WebSocket 已启动、端口与 Token 一致，再到「诊断 → 桥接日志」
查看原因。需要逐次确认时，按 QQ 消息提示在 30 秒内回复；超时会自动拒绝设备操作。
