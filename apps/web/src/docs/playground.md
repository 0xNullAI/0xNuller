# Playground

把设备接进游戏。玩的时候，游戏里发生的事会变成设备上的一次反馈。

## 现在有什么

**贪吃蛇** —— 方向键或 WASD 控制。吃到食物给一次短反馈，撞墙或咬到自己给一次稍强的。

**剧本杀** —— 还没做，列表里能看到但点不开。

## 强度是谁说了算

游戏只能"请求"一次反馈，说不出具体数值。实际多强由你在**设置 → 设备安全**里定的上限决定。

这一条没有例外：没有哪个游戏能越过你设的上限，也没有哪个游戏能让你调不了。玩到一半想改，随时去设置里改，立刻生效。

## 没连设备也能玩

界面上会写着"未连接设备，纯游戏模式"。这时候就是普通游戏，不会有任何输出。

## 停止

和别的地方一样：设备栏上的停止按钮始终在，随时一下就停。游戏不会挡住它。
