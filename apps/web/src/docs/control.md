# Control

手动控制自己的设备。

## 连接设备

点击顶部横栏的「连接设备」。已连接的设备会显示在同一横栏中，可以继续连接或单独断开。

设备安全设置位于 **软件设置 → 设备安全**。

## 调整强度

A、B 两个圆环对应两个通道。

- 点击 **− / +** 单步调整。
- 按住按钮连续调整。
- 圆环下方显示当前通道上限。

## 播放波形

1. 选择 A 或 B 通道。
2. 从波形列表中选择内容。
3. 点击圆环上方的播放按钮。

播放模式支持单曲、列表和随机。也可以从本地文件或 Market 导入波形。

## 一键开火

展开「一键开火」，先播放对应通道的波形，再设置临时增加量。按住「按住开火」增强，松开恢复。

## 多个设备

连接多台设备后，每台设备都有独立状态和控制区。点击设备标题可切换当前波形目标。

负鼠和传感器会在连接后显示各自的控制或读数。

## 停止

设备连接后，顶部横栏会提供归零或停止按钮。切换模块时仍然可见。
