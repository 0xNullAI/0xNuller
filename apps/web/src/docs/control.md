# Control

自己控制自己的设备。**没有 AI，也没有别人**——这一页里的每一个数字都是你自己按出来的。

不需要账号，不需要模型密钥，不需要进房间。连上设备就能用。

## 连接设备

页面顶部常驻的是全软件统一设备横栏：

- **连接设备** —— 打开一次选择器，郊狼主机、爪印传感器、灵猫边缘传感器、负鼠振动控制器
  都在里面，选中哪台就接哪台。每种一次只接一台，**再点一次可以继续接下一台**。
- 已经接上的设备显示为可横向滑动的标签，**各自有断开按钮**。断开传感器不会把郊狼一起断掉。
- 安全上限与授权统一在**软件设置 → 设备安全**中调整。

横栏会显示设备类型、电量、待机/输出状态和当前强度，不显示没有辨识意义的原始蓝牙 ID。

## 调强度

两个圆环就是 A、B 两个通道，下面各有一对 **−** / **+**。

点一下走一格，**按住不放会连续走**，松手停在当前值。圆环下方的小字是这个通道的上限，
强度永远碰不到上限以上——按住不放也一样。

## 放波形

1. 上面的 **A 通道波形 / B 通道波形** 切换你要编的是哪个通道。
2. 在波形格子里点选，被选中的会带上序号角标，那就是这个通道的播放列表。
3. 回到圆环上方的 ▶ 按钮启动，再点一下暂停。两个通道各放各的，互不影响。

**单曲 / 列表 / 随机**决定列表怎么走；选了列表或随机之后旁边会出现切换间隔（10 秒到 10 分钟）。

波形不够用：**导入波形**读本地 `.pulse` / `.zip` 文件，**从市场导入**直接从社区拿。
导入的波形是全软件共用的，在 Agent 里也看得到。

## 一键开火

先启动对应通道的波形，再在**一键开火**里设定临时增加量。按住 A 或 B 的**按住开火**，该通道会在安全上限内临时增加强度；松手、划出、取消触摸或切走页面都会恢复到按下前的强度。

开火期间普通的强度加减会暂时锁住，避免“恢复到哪里”产生歧义。点**全部归零**属于紧急停止：会立即取消开火并归零，之后松手也不会把旧强度恢复回来。

## 其他设备

接上之后才会出现。

**负鼠振动控制器** —— 和郊狼一样的双通道加减和一键脉冲，用的是它自己那套强度上限
（设置 → 设备安全里的负鼠上限），不是郊狼的。

**传感器** —— 只显示读数：爪印显示最近一次触发事件，灵猫显示压力值。**它不会去驱动任何输出**。
「传感器一动就加强度」这种联动需要一套单独的授权界面，那个还没做，所以这里不做。

## 停止

两个地方都是一下就停：

- 这一页中间的**归零**——郊狼和负鼠一起清零
- 设备栏上的全局安全按钮——待机时显示中性的**归零**，确实有“强度 + 同通道波形”输出时才变成红色**停止**。只要有设备连着它就在，切到别的模块也还在

## 切走了会怎样

切换到别的模块，Control 就交出控制权并停止输出。切回来重新连接不需要重来一遍——设备还接着，
强度从零开始。
