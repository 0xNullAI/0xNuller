# Video

Video 使用最新摄像头画面主持短时场景，并可在明确授权范围内控制郊狼或负鼠。

## 开始

1. 在「软件设置 → AI → Video」中单独配置服务商、凭据，并选择明确支持图片输入的模型。
2. 打开 Video，选择前置或后置镜头，再点击「开启摄像头」。
3. 连接郊狼或负鼠，选择目标通道，设置强度上限、授权时长、模型节奏与最新帧刷新频率。
4. 按需开启「小步增强」或「短时脉冲」，确认授权后开始。
5. 随时暂停、停止；需要时点击「紧急停止」。紧急停止后必须重新授权。

一次授权最长 15 分钟。摄像头以 0.2–5 秒的独立频率刷新内存最新帧，模型按 5、10、15 或 30 秒节奏保持单请求在途；处理期间的新画面会替换尚未处理的旧画面。设备效果不会阻塞下一次观察，但每次写入仍受授权、设备控制权和全局安全设置约束。

暂停、停止、切换模块、隐藏页面、关闭或刷新页面、摄像头结束、设备断开、授权到期、观察超时或连续两次模型失败都会中止当前推理并停止授权目标，不会自动恢复。紧急停止会覆盖所有已连接输出目标；停止确认失败时保持安全锁定。

网页摄像头需要 HTTPS 或 localhost。图片不会写入对话、浏览器存储、账户同步、导出或日志；场景回应只在当前页面内存中显示。
