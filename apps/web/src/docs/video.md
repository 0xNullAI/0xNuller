# Video

Video 使用摄像头画面提供短时、只读的视觉解释，不连接或控制设备。

## 开始

1. 在「软件设置 → AI → 文本模型」中选择明确支持图片输入的模型。
2. 打开 Video，选择前置或后置镜头，再点击「开启摄像头」。
3. 确认实时预览后，可手动采集，或设置自动采样间隔并开始解释。
4. 随时暂停、停止或关闭摄像头。

每次会话最多解释 3 步并在 90 秒内结束，步骤之间至少间隔 10 秒。模型请求只会有一个在途；处理期间采集到的新画面会替换尚未处理的旧画面。

网页摄像头需要 HTTPS 或 localhost。切换模块、隐藏页面、关闭或刷新页面都会停止采集和解释，不会自动恢复。

图片不会写入对话、浏览器存储、账户同步、导出或日志。解释文字只在当前页面内存中显示，刷新后消失。
