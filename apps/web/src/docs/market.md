# Market

社区上传的波形和场景，一键导入到自己的库。

## 找东西

顶部切「场景」或「波形」，还可以按「单人 / 多人」筛选、搜名字和标签。

找到喜欢的点进去，点「导入」。

- 导入的**场景**在 Agent 和 Voice 里立刻能选
- 导入的**波形**在设备控制里能选

导入是复制到你本机的库，之后作者改动不会影响你已导入的那份。

## 上传自己的

需要先登录——内容归属绑定到账号。点右上角「上传」。

上传的是波形数据或场景文本，不包含你的任何设置或对话记录。

## 内容由社区提供

上传的内容没有经过审核。导入一个陌生场景之前，可以先点进去看看正文写了什么。

场景只影响 AI 的说话风格和倾向，**改变不了你设的强度上限**——那个在你自己的设备上
执行，任何场景都绕不过去。
