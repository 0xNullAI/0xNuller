# 介绍

猫愿是一个陪伴聊天应用：和 AI 角色、朋友聊天，也可以连接支持的设备。

- **消息** — AI 角色、私聊和群聊都在这里
- **联系人** — 找朋友、建群
- **发现** — 角色、场景和波形
- **设备** — 连接设备、手动控制
- **我的** — 账户与设置

第一次使用：在「发现」选一个角色，点「开始聊天」。角色是和你聊天的 AI；场景只是聊天发生的环境，在聊天里点名字 → 场景 选用。

## 安全须知

- 从最低强度开始，变更贴片位置后重新测试。
- 不要将电极放在胸口、头部、颈部、破损或发炎的皮肤上。
- 心脏起搏器、心血管疾病、癫痫、孕期或身体状况不确定时，请勿使用或先咨询专业人士。
- 不要在睡眠、洗澡、饮酒后、驾驶或操作机械时使用。
- 出现刺痛、灼热、麻木、头晕、心悸或其他不适时，立即停止并断开设备。

请始终确保能够通过设备电源或电极线物理断开输出。

## 第一次使用

1. 打开设备和手机或电脑的蓝牙。
2. 进入 **Control**，点击顶部的「连接设备」。
3. 打开 **我的 → 设备安全**，确认通道上限。
4. 从低强度开始测试，再选择波形播放。

设备连接后，顶部横栏会显示状态，并提供归零或停止操作。

## 通用设置

- Agent、Voice 和 Video 共用「我的 → 通用」中的 AI 网络代理。
- 实验性通用设备默认隐藏，只能在「我的 → 关于」中开启一次。

## 账户

Chat、个人资料和同步功能需要登录。注册需要邮箱。

## 连不上设备

- 确认设备已进入配对模式。
- 网页版请使用支持蓝牙的 Chrome 或 Edge，并允许蓝牙权限。
- 安卓版拒绝过权限时，请前往系统设置重新开启。
- 如果设备曾连接其他手机或电脑，先断开旧连接后重试。
- 频繁断开时，检查距离、电量和系统蓝牙状态。
