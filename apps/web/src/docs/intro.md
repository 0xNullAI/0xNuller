# 介绍

0xNuller 让你用 AI 控制 DG-Lab 的设备。打字、说话、或者交给房间里的另一个人。

五个部分，从左边侧边栏顶部切换：

- **Agent** — 打字，AI 帮你操作
- **Voice** — 说话代替打字
- **Chat** — 多人房间，别人可以控制你
- **Playground** — 把设备接进游戏
- **Market** — 别人做好的波形和场景，一键拿来用

不需要注册，打开就能用。账号只用来跨设备同步。

## 安全须知

这个软件会让电流通过你的身体。下面几条不是免责声明，是操作方法。

**开始之前**

- 从最低强度开始。换了贴片位置也要重新从低往高试——同样的数值在不同部位差别很大。
- 确保你能随时物理断开：长按郊狼电源键关机，或者直接扯掉电极线。
- 保持清醒，不要在困倦或饮酒后使用。

**绝对不要**

- 电极放在**胸口、头部、颈部**——电流经过心脏或大脑是危险的
- 放在破损皮肤、炎症区域或异常敏感的部位
- 有**心脏起搏器**或其他植入式电子设备时使用
- **心血管疾病、癫痫、孕期**，或身体状况不确定时使用——先问医生
- 独处时用高强度，或睡着时保持输出
- 洗澡、驾驶、操作机械时使用

**出现刺痛、灼热、麻木、头晕、心悸，或任何说不上来的不适，立刻停。**

停止的三种方式，从快到慢：按屏幕上方设备栏最左边的红色停止按钮、长按郊狼电源键
关机、扯掉电极线。

停止按钮只要有设备连着就在，切换模块也不会消失。

## 第一次使用

大概三分钟。

**一、打开郊狼。** 长按电源键开机，手机或电脑的蓝牙也要打开。之前配对过别的设备的话，
先在系统蓝牙设置里把它「忘记」。

**二、连接。** 侧边栏顶部选 **Agent**，点「连接蓝牙」，在弹出的列表里选名字带
`47L121` 或 `D-LAB` 的那个。

> 搜不到？把郊狼两侧的滚轮**同时向下按住 3–5 秒**，直到屏幕闪烁——这时它进入配对模式。
> 然后再点一次「连接蓝牙」。

连上之后屏幕最上方会出现设备栏，显示设备名、电量和当前强度，最左边是停止按钮。

**三、设上限。** 侧边栏最下面点头像 → 软件设置 → 设备安全。最上面两条是 A、B 通道的
上限，默认 50（郊狼协议范围是 0–200）。

**先别急着调高**，从默认值开始，实际感受过再决定。

**四、试一次。** 回到 Agent，输入框里打「帮我把 A 通道调到 5」，回车。AI 会请求你
确认这条指令，点「允许」。感觉到了就说「停」，或者按停止按钮。

## 上限是怎么生效的

**软件设置 → 设备安全**里的上限，是在**你自己的设备上**执行的。

房间里的其他人、AI、游戏逻辑给出的任何数值，都会先被压到这个范围内，再发给郊狼。
他们说了不算。

三个最值得设的：

- **通道上限** — 最重要的一个，任何来源都不能让这个通道超过它
- **冷启动上限** — 从零开始时单次能拉到多高，防止一上来就是满档
- **单次调节步长** — 一条指令最多能加减多少，设小一点变化更平缓

这套设置**所有部分共享一份**。在 Agent 里调完，Chat、Voice、Playground 立刻就是这个值。

## AI 不是安全控制器

它可能误判你的话，蓝牙和网络也可能卡顿或断连。

默认每条设备指令都要你确认。可以改成「确认后 5 分钟免确认」，或者「完全放行」——
但**完全放行不过夜**，重开软件会自动回到每次确认。这条不能关。

## 账号

登录只用来同步你的波形、场景和市场上传。

**它不给任何人控制你设备的权力**——哪怕是你自己在另一台设备上登录了同一个账号。
设备控制权始终需要当面授予，随时可以撤销。

注册不要邮箱，代价是**密码找不回**。注销是真删除，不是标记。

## 数据存在哪

- 波形、场景、设置、对话记录 — 浏览器本地，清除站点数据会丢
- API Key — 也在本地，**不加密**，同源脚本和浏览器扩展都读得到。真需要保密请自建代理
- 账号 — 用户名和密码哈希在服务端，密码用 PBKDF2-SHA256，21 万轮

## 连不上设备

先按上面说的进配对模式。还不行就依次检查：

- **浏览器** — 必须是 Chrome 或 Edge。Safari 和 Firefox 不支持网页蓝牙，请用安卓版
- **地址** — 必须是 HTTPS 或 localhost，普通 HTTP 页面用不了网页蓝牙
- **权限** — 安卓版需要蓝牙权限，拒绝过的话去系统设置里重新打开
- **配对残留** — 之前和别的设备配过，先在系统蓝牙里「忘记」

连上又频繁断开多半是距离或电量。先把上限调低——断连重连的瞬间强度可能跳变。
