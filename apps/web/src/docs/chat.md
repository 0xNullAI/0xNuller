# Chat

Chat 需要登录，用于群聊、私聊和远程互动。

## 群聊

- 未加入群聊时，Chat 会显示公开群列表。
- 在 **消息** 页点击 **新聊天 → 创建群聊** 创建群聊，或输入群号加入。
- 关闭「公开到大厅」可创建私密群。
- 打开群聊后，地址栏中的链接可以直接分享给其他人加入。

## 私聊

互相关注后，可以在 **联系人** 或对方主页发起私聊。私聊和群聊都显示在 **消息** 列表中。

## 群聊互动

- 发送文字、图片或语音消息。
- 点击成员进入设备控制。
- 按住「开火」临时增强，松开恢复。
- 群主可以添加群 AI 并设置群聊选项。

## 结束控制

退出群聊、切换模块或关闭相应授权后，当前远程控制会结束。

设备安全设置位于 **我的 → 设备安全**，顶部横栏可随时停止输出。
