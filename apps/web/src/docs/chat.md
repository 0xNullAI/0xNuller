# Chat

多人房间。房间里的人可以在**你设的上限内**控制你的设备。

## 进房间

打开 Chat 会自动进「公开大厅」——那是一个常驻房间，随时有人在。

想要私密房：侧边栏「房间」→ 建房间 → 关掉「公开到大厅」→ 创建。把生成的房间号发给
对方，只有拿到号的人能进。

## 房间里能做什么

- 点成员卡片，控制他/她的设备
- 按住「开火」按钮临时加强度，松手回落
- 给房间设场景，让 AI 参与进来
- 随时关掉「允许 AI 控制我的设备」

对方能给出的任何数值，都会先被压到**你**在软件设置里定的上限内。他们说了不算。

## 交出控制权

三种方式都会立刻生效，对方会看到你的设备变成不可控：

- 点右上角的离开按钮
- 切换到别的模块
- 关掉「允许 AI 控制我的设备」（只针对 AI）

**切换模块就交出控制权**是设计如此：你在看哪个模块，就只有那个模块能下指令。
切回来就恢复。

## 需要账号吗

不需要。进房间、聊天、被控制都不用登录。
