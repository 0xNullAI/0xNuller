# Chat

Chat 需要登录，用于房间聊天、私聊和远程互动。

## 房间

- 未加入房间时，Chat 会显示公开房间列表。
- 点击侧边栏 **房间 → 新建 / 加入房间** 创建房间或输入房间号加入。
- 关闭「公开到大厅」可创建私密房间。
- 使用房间号加入指定房间。

## 私聊

互相关注后，可以从对方主页发起私聊。已有私聊显示在侧边栏「私聊」中。

## 房间互动

- 发送文字、图片或语音消息。
- 点击成员进入设备控制。
- 按住「开火」临时增强，松开恢复。
- 房主可以添加 Agent 并设置房间选项。

## 结束控制

离开房间、切换模块或关闭相应授权后，当前远程控制会结束。

设备安全设置位于 **软件设置 → 设备安全**，顶部横栏可随时停止输出。
