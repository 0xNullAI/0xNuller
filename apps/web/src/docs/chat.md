# Chat

群组。群里的人可以在**你设的上限内**控制你的设备。

## 进群

登录后打开 Chat 会自动进入「公开大厅」。

新建房间：侧边栏「房间」→「建房间」。想要私密群，关掉「公开到大厅」再创建。把生成的群号发给对方，
只有拿到号的人能进。公开与否随时可以改，关掉之后大厅里立刻就没有它了。

**群是长期存在的**，人走光了也不会消失，聊天记录留着。每个群保留最近 1000 条消息，
更早的会连同里面的图片一起删掉——所以重要的东西不要只存在群里。

建群的人拿到一把**群主密钥**，存在这台浏览器里。它是之后修改房间设置的凭证。

私聊列表在侧边栏「私聊」。互相关注后，可以从对方主页开始私聊。

## 群里能做什么

- 点成员卡片，控制他/她的设备
- 按住「开火」按钮临时加强度，松手回落
- 加一个 Agent 进群，在消息里 **@ 它**让它参与
- 随时关掉「允许 AI 控制我的设备」

对方能给出的任何数值，都会先被压到**你**在软件设置里定的上限内。他们说了不算。

## 交出控制权

三种方式都会立刻生效，对方会看到你的设备变成不可控：

- 点右上角的离开按钮
- 切换到别的模块
- 关掉「允许 AI 控制我的设备」（只针对 AI）

**切换模块就交出控制权**是设计如此：你在看哪个模块，就只有那个模块能下指令。
切回来就恢复。

## 账号

Chat 需要登录。登录后才能进入房间、聊天、关注和私聊。
