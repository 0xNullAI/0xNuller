# 0xNuller Web

中文 | [English](README.en.md)

`0xNuller` 的统一网页版外壳。Control、Chat、Agent、Voice、Video、Market 和 Playground 在同一
SPA 中按路由加载，共用账户、设备横栏、设置、主题和弹窗层。桌面版使用单列侧栏，聊天时在导航下显示消息列表；手机端
以消息列表为首页，底部导航进入联系人、发现、设备和账户。左上角不再提供模块切换器。
主站所有产品路由共用一个入口登录页；未登录时不挂载模块，登录后保留原路径进入目标页面。邮箱未验证的 Chat 仍引导至账户验证。
`/u/:username` 也受这一登录门禁保护。登录用户可看资料、关注数和公开相册；旧资料可见性选项已停用，
照片仍可逐张设为公开、好友或私密，旧私密照片不会自动公开。屏蔽和举报继续有效。

## 路由

| 路径                 | 模块                                                        |
| -------------------- | ----------------------------------------------------------- |
| `/`                  | 桌面聊天窗／手机消息列表                                    |
| `/control`           | 手动控制                                                    |
| `/chat`              | 房间与私聊                                                  |
| `/agent`             | 文字 Agent                                                  |
| `/voice`             | 实时语音                                                    |
| `/video`             | 视觉控制                                                    |
| `/market`            | 场景与波形社区                                              |
| `/playground`        | 游戏互动                                                    |
| `/settings/:section` | 我的设置列表与二级页；可刷新、复制链接和使用浏览器前进/后退 |

主站为 <https://0xnullai.com>。历史独立子域已下线，模块统一通过上表中的主站路径访问。

## 结构

```text
src/Shell.tsx        统一外壳与账户门禁
src/Sidebar.tsx      桌面单列导航与聊天消息列表
src/UnifiedInbox.tsx AI、真人私聊、群聊的账号绑定摘要列表
src/DeviceBar.tsx    全局设备状态与停止操作
src/settings/        统一设置
src/modules/         各模块的懒加载入口
src/docs/            用户文档
```

设计令牌和通用组件位于 `packages/platform/ui`。模块不应重复实现外壳已经提供的设备连接、
设置或导航入口。

设置列表的「个人记忆」二级页可管理服务器保存的偏好、人物、事件和其他记录，仅账户本人可见。
角色关系中的长期记忆另有默认关闭的自动发现：后台只从本人原话提出待核对候选，用户确认后才进入
Agent 检索；较早会话可按来源回看，长会话概述与已确认事实保持分离。详情见
[Auth Memory 说明](../../workers/auth/README.md)。现有聊天历史迁移和独立线上备份仍须单独验收；
读取或保存失败时保留用户编辑并提供重试，不写本地记忆副本。

AI 设置按 Agent、Voice、Video 分 profile 展示，但三者共用 catalog-driven 字段控件；Agent 与
Video 的模型发现走 `@dg-agent/agent-browser`。设置 UI 不直接拼 provider 请求地址或复制 provider
SDK 分支。

## 性能与模块生命周期

功能模块保留会话状态，同时通过 `useModuleActive` 暂停隐藏页面的键盘和游戏计时器。
设备执行仍独立校验 lease。「我的」打开分组设置列表，点击条目进入二级页面；手机占整页，
桌面保留左侧导航，让设置占据主内容区。切换导航会关闭设置。打开设置会撤销模块设备租约，设备连接和全局停止保留。
设置子页使用 `/settings/overview`、`/settings/account` 等地址；旧 `/settings` 链接仍进入账户页。
设置、文档、联系人和资料内容按需加载；只有进入波形/数据/诊断/设备安全页才挂载 Agent 设置 owner，
通用设置不初始化 Agent。
`verify-web-bundle.mjs` 将入口和必需 bootstrap 的静态依赖一起计入 300 kB gzip 预算。
浏览器需 Chrome/Edge 111+、Safari 16.4+ 或 Firefox 128+；过旧环境在模块启动前显示升级提示。
有 Web Bluetooth 的浏览器可直接连接设备，其他环境使用 Android 应用。

桌面根路径复用 Agent 聊天窗，消息栏把 AI、真人私聊和群聊摘要合并排序；Market、设备和设置保留同一列导航，隐藏消息列表。手机根路径只挂消息列表，
点入 AI／真人聊天后才懒加载对应模块；返回消息列表会撤销该模块的设备租约，不断开实体设备，
全局停止仍可用。原有 `/agent`、`/chat`、`/voice`、`/video`、管理设置及设备连接路径保留。
AI 和真人的传输仍由各自后端负责；收件箱只读取账号绑定的摘要，绝不把消息正文存入前端列表。
AI 摘要首次只读取 100 条，继续浏览时按服务端游标加载下一页；刷新会重读本次已展开的页数，
避免自动刷新把用户正在看的较早会话从列表中移除，也避免默认扫描全部历史。
AI、私聊或群聊摘要暂时读取失败时，同账号此前显示过的对应条目会保留为待重新验证状态，
清除旧时间与未读数，也不提供旧的标为已读操作；刷新成功后以服务器摘要替换。

角色编辑离页保护由统一 history owner 执行：侧栏、手机底栏、页面跳转及带序号的同文档
前进/后退都先询问未保存编辑；取消不切换页面或设备租约。已保存草稿不阻挡，账号撤销立即
绕过旧守卫，停止/授权操作不进入导航守卫。浏览器完整离页继续由编辑器 beforeunload 处理。
对 Shell 启动前没有序号的历史条目，取消会恢复当前可见 URL，可能替换该旧条目的地址。

管理设置的现有「订单与退款对账」下方新增「文字 Credit 待核对任务」。只展示受管理权限保护
的任务计数与财务状态，可保存不可修改的核对备注；备注成功明确提示「未改变余额或账务状态」。
同页还显示媒体 Credit 待核对任务的预留、扣费和账本证据，可分页记录审计备注；此入口不补扣、
退款或交付媒体，账务处理仍须人工核对。
提交使用原观察状态，后台变更会返回冲突并保留待提交内容。内部 reservation capability、
完整模型元数据及聊天正文不进入此界面。后端需先应用 Auth 0040；不提供猜测用量扣费按钮。

账户 Credit 流水统一显示文字、Voice、图片/自拍、生成视频、主动消息与原充值/奖励记录。
一条预留及其usage账本合并展示，金额缺失显示「未记扣款」而非0；释放、有效冻结、过期、
需核对分别显示。详情中缺失的会话/任务/价格版本明确未知，生成视频与旧视觉记录不混称。
刷新失败保留已读记录并报错，此面板只读，不触发补扣或重试生成。新版需要Auth timeline响应，
老服务缺少能力时明确报错，不将旧字段误解为新状态。

管理设置中的账务对账保留订单/文字审核，并新增 Voice 冻结过期只读队列（需 Auth 0045）。
可按账户和本地起止时间筛选，分页查看时长、请求报价与真实扣款。人工备注不可修改，失败重试
复用事件编号；切换账户会重建审核面板。备注只留痕，不扣款或强制完成账务异常。
